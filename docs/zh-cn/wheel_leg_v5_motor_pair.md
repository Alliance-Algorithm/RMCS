# V5 轮腿髋、膝电机的相对圈数与工作区

## 电机零点与 URDF 标定

DM 驱动 `angle = sign*(raw - offset)`，`set_reversed()` 后 `sign=-1`，即 `angle = offset - raw`。**电机内部零点（raw=0）对应 V5 训练名义姿态**：

```text
default_joint_pos = [L_joint1, LL_joint1, R_joint1, RR_joint1]
                  = [0.42, -0.13742282595254576, -0.42, 0.13741557625658019] rad
```

因此取 `offset = default_joint_pos`，`/wheel_leg/*/angle` 即 URDF 关节角。控制器对外传的都是 URDF 参考系角度，便于接入 RL。遥控模式映射：

- 左中右上：闭环到电机内部零点，其 URDF 角 = `default_joint_pos`（`calibrated_zero_leg_position`）。
- 左下右中：闭环到 URDF 零点 `[0, 0, 0, 0]`（`urdf_zero_leg_position`）。
- 双中：进入 RL。

## 坐标和闭链关系

本结论使用 `urdf_v5.0.urdf` 的关节坐标及 V5 闭链研究模型的六个闭合约束。RMCS 中左髋、左膝、右髋、右膝分别对应 `L_joint1`、`LL_joint1`、`R_joint1`、`RR_joint1`。电机零位和方向必须与这些 URDF 坐标一致；研究模型的 `active_motor_mapping_verified` 仍为 `false`，所以实机启用前应核对四路反馈方向。

设真实大腿与小腿内角为 `θ`，两个主动电机的连续角度为 `h` 和 `k`。原始 URDF 的 `joint2` 安装偏角为 2.3573 rad，因此：

```text
θ_left  = π - 2.3573 + q_L_joint2
θ_right = π - 2.3573 - q_R_jonit2

d_left  = h_left - k_left
d_right = k_right - h_right
```

闭链几何给出单调但非线性的关系 `d = f(θ)`。在参考姿态 `h_left=+0.42 rad`、`h_right=-0.42 rad`，几何求解结果为：

| 内角 θ | 左侧 d (rad) | 右侧 d (rad) |
| ---: | ---: | ---: |
| 30° | -0.473723 | -0.473740 |
| 45° | +0.001805 | +0.001794 |
| 70° | +0.604867 | +0.604860 |
| 90° | +1.027558 | +1.027552 |
| 110° | +1.428468 | +1.428462 |
| 120° | +1.628923 | +1.628916 |

对 30–120° 连续求解，左右两侧的 `d` 均严格递增（120° 两个值为按 90–110° 段斜率 `0.0200455 rad/deg` 外推），最大闭链残差小于 `2e-15 m`。两台电机共同旋转时 `d` 基本不变；在参考模型中，共同角从 `−2π` 扫至 `+2π`，相同内角对应的 `d` 变化小于 `2e-5 rad`。所以两个电机**都不需要单独的绝对角限位**，正常工作区限制的是带有左右侧符号约定的相对角：

```text
-0.47375 rad ≤ d_left, d_right ≤ +1.62892 rad
```

若内角固定，`ω_knee = ω_hip`。内角变化时，左侧 `ω_knee = ω_hip - f′(θ)·θ̇`，右侧 `ω_knee = ω_hip + f′(θ)·θ̇`。在上述范围，数值求得 `f′(θ)` 约为 1.13–2.17 rad/rad。因此两个电机有时同向、有时反向；是否可行取决于**全过程的相对角**，不能要求它们始终同向。

## RMCS 的选圈数规则

四台 DM-J8009-2EC 关节电机须先在达妙调试助手中将 `Control Mode` 设为 `VEL` 并写入参数；仅发送速度帧不会改变电机模式。按[DM8009 使用说明书 V1.0](https://docs.openarm.dev/assets/files/dm8009-90ee7f15d06666e15afd49e5d5417150.pdf)第 7 页，独立速度模式控制帧 ID 为 `0x200 + 电机 CAN ID`，`D[0..3]` 为小端 float32 的 `v_des`（rad/s）；其余四字节按[达妙 SDK](https://github.com/dmBots/motor-sdk/blob/main/Python%E4%BE%8B%E7%A8%8B/u2can/DM_CAN.py)填零。当前系统使能帧使用基础 ID。控制器只有在四台电机均反馈 `status_code=1` 时才发送非零速度；状态服务中可查看每台电机的状态码。

差值区间宽度约 `1.90223 rad`，小于一圈。即使两个电机的单圈反馈在不同位置过零，也能唯一选择膝电机相对髋电机的整数圈数，使 `d` 落在机械分支内。共同增加或减少 `2π` 不改变腿的形状；控制器从这些共同圈数中选使两电机**最大行程最小**的一支。它不会对髋、膝各自独立选择最短弧。

RL 目标若超出差值区间，控制器保留其平均转角，将差值投影到工作区内侧 `0.04 rad`。同侧两个电机按同一轨迹比例推进，所以两个有效端点之间的整条插值轨迹都满足差值工作区。

实机反馈显示左侧 `d≈1.5738 rad`，超过原 110° 的工作区上界，但用户确认真实机械行程可超过 110°，故工作区上界已按 120° 外推放宽到 `d=1.62892`（软件工作区，非实测硬限位）。工作区和纠偏范围分开：实测 `d` 在工作区外 `0.25 rad` 以内时，先冻结其他目标，保持平均转角的成对轨迹，以 `2π rad/s` 最大参考速度退回最近工作区边界内 `0.04 rad`；返回后再跟随遥控或 RL 目标。DM 关节采用速度模式，电机内环闭环速度，控制器做 PC 侧角度环：`v_des = 轨迹前馈 + angle_kp·成对选圈后的连续角度误差 (+ 纠偏前馈)`。由于边界目标距当前姿态很近，角度环输出本身很小，回收期间在角度环之上叠加 `recovery_feedforward_velocity = 2.0 rad/s` 的前馈速度（方向为把差值推回最近边界），并按越界量在 `recovery_feedforward_range = 0.10 rad` 内线性收敛到 0，防止越过边界；角度环仍负责收尾。超过纠偏范围、反馈失效、轨迹异常或通电后 3 秒内未退回仍锁存故障。`0.25 rad` 是暂定的软件纠偏范围，**不是已测得的机械硬限位**；更远的实机行程需测量后单独确认。

例如左侧示例姿态 `[-2.1, -3.28]`（旧安全姿态，见下文验证）到名义姿态 `[+0.42, -0.137423]`，髋、膝分别正转 `2.52` 与 `3.142577 rad`。对膝单独做最短弧会选反方向；成对选圈数会保留两台电机的可行路径。

## 验证范围

本机 `isaaclab` 环境中的 V5 PhysX 闭链模型加载了 19 刚体、6 闭合约束。对 30、45、70、90、110° 及共同转过一圈的姿态，逐个写入闭合解并步进一帧，最大约束间隙小于 `9e-7 m`；读回的内角与输入相差不超过 `0.005°`。样本与模型哈希保存在 [PhysX 探针结果](wheel_leg_v5_motor_pair_physx_result.json)。注意：新工作区上界 120°（`d=1.62892`）是按 90–110° 段斜率外推的，**尚未单独跑 PhysX 单帧验证**，实机启用前需补测。安全姿态到名义姿态的 201 个电机插值点也都能闭合，内角单调从 `97.515°` 变到 `67.855°`，最大闭合残差小于 `2e-16 m`。C++ 选弧测试覆盖反馈跨圈、左右对称、安全到名义姿态、完整插值轨迹与越限目标投影。

这属于**几何和单帧 PhysX 验证**，尚非实机闭环验证。研究模型原先使用 35–80° 膝限位；为检查用户提供的 30–120° 真实范围，仿真中临时修改了这两个关节的限位。30° 时研究气弹簧的滑块位置为 `−0.00816 m`，低于其未经过硬件确认的旧下限 `−0.00547 m`；探针仅在内存中将该下限放宽到 `−0.012 m`，未修改研究资产或假定气弹簧行程已经实机核实。

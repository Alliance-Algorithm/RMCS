控制参数只有 Kp/Kd 不同，轨迹配置相同。两次初始电机位置差为 -0.07477/-0.06905 rad，平均姿态差约 -4.12°，因此重力负载并不完全相同；两组同时改变了 Kp 和 Kd，也不能把结果全部归因给一个增益。161 段保持目标的事件序列在移除初始角偏移后相同，事件比较无警告；采样时间在零阶保持边界产生的插值差异单独保留，未把插值误差误报为轨迹幅值变化。

## 为什么选 120/3 进行下一轮

- Kp 从 60 增到 120，Kd 从 2 增到 3。仍是 `tau=Kp*(q_ref-q)-Kd*dq`，无积分、速度前馈或重力前馈；目标 50 Hz，PC PD / MIT 发送 / 采样均 1000 Hz。
- 旧包 5–90 Hz 的五组局部模型，加反馈增益±5%及额外 0/1 ms 命令延迟，120/3 的最坏线性极点实部约 -8.83/s；200/4 出现 +4.95/s。因此 120/3 是增大恢复力的有限候选。60/2 的最坏极点更负，本次选择不是宣称线性稳定裕度更大。
- 在旧 60/2 包的状态与目标完全冻结时，120/3 请求峰值约 13.83 / 16.02 Nm。此数字只是代数检查，不能预测新轨迹的真实峰值、运动或稳定性。
- 两轴共同作用于腿形。提高两轴 PD 并增加相反方向的目标偏移，使辅助膝电机确实获得克服气簧负载的恢复力，而不是让其仍以几 Nm 被动跟随。

## 验收与拟合口径

先看新包是否真正提高实测差模运动和负载覆盖，再检查力矩饱和、振荡、高频响应、温度及时间戳完整性。旧包和新包的增益、轨迹均改变，因此两包差异不能单独归因于 Kp/Kd；要证明增益更优，需固定同一轨迹再比较。

气簧使用已有静态拟合曲线与已核对的安装几何；完整闭链模型固定车体并保留重力。先拟合执行器/机械残差，再做独立段自由闭环回放。控制器必须接收仿真自身反馈，不能回灌实测状态得到虚假贴合。通过后才冻结执行器参数与随机化范围，进入训练。现有正式 RL 的 50/200 Hz 链尚未因本次独立 50/1000 Hz 采集自动迁移。

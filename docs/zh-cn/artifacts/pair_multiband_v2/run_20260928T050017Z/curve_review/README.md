# 上次左腿 PD bag：曲线与参数可辨识性

分析对象 `left-pair-pd-20260928T050017Z`，60/2、目标 50 Hz / PC PD 1000 Hz。不是刚完成的 120/3 带载新包。

## 实测结论

`measured_tracking_and_torque.png` 左列为整体摆动段 1，右列为相对运动段 109；蓝色目标、橙色实测，下排为两电机请求力矩。原始采样 1000 Hz，图上每 10 点显示一点，不平滑。角度以该段首实测值为零；差模是辅助膝主动轴与髋主动轴的角差，不是大小腿内夹角。

段 109 的目标角差峰峰值约 6.63°，实测约 0.39°；膝部请求峰值约 5.56 Nm。全运行段两轴请求峰值 6.49 / 7.40 Nm，没有触发 40 Nm 限幅。整体摆动有有效激励，但伸缩激励明显不足。`both_motor_tracking.png` 分别展示两电机自身的目标和反馈。

## 已做的模型拟合与独立回放

采用之前由本包开发段拟合的等效共模模型：

`tau_hip+tau_aux = M*c_ddot + B*c_dot + Fc*tanh(c_dot/eps) + Gs*sin(c) + Gc*cos(c) + bias`

其中 `c=(q_hip+q_aux)/2`。平滑尺度只按开发集逆动力学残差选择并冻结；未用留出回放调参。该模型描述整个装配体的合成响应，参数不能解释为某个电机本体的摩擦/惯量，也未替换气簧静态曲线。

用段首实测位置及位置微分估计的速度初始化，然后以仿真自身反馈计算 PD；只持续输入记录中的目标，不回灌后续实测 q/dq。以 1 ms 积分、理想反馈与力矩、固定段首角差进行简化共模闭环回放。在未参与拟合的多正弦段 71 / 81 上，平均角度预测对实测的 RMSE 为 **0.61° / 0.45°**（各段去掉头尾 1.5 s）。图见 `common_forward_validation.png`，原始指标见 `forward_validation.json`。

这证明旧包能支持共模初步拟合，而不是完整闭链、差模或电机动态已经辨识完成。换向停滞与高频小幅段仍有误差；有效摩擦、反馈动态和气簧耦合尚不能充分分离。

## 同轨迹下的 PD 候选比较

固定上述模型和旧目标，仅在开发段比较 60/2 与 120/3：

|开发段|60/2 模型预测目标跟踪 RMSE|120/3 模型预测目标跟踪 RMSE|
|---|---:|---:|
|45|2.78°|1.83°|
|57|3.02°|1.93°|
|127|3.02°|1.93°|

这是**整体摆动的模型预测**，没有产生 120/3 的真实对照数据，不预测膝部屈伸改善，也不证明新增大轨迹下的稳定性。结合既有局部高频模型筛查，120/3 是有依据的实机候选，不能叫“由这个 bag 辨识出的最优 PD”。最终应以更充分的带气簧实机运动和完整两轴自由回放验证。

本地训练资产 `isaac_wheeled_rl_train/model/纯底盘_v5_232mm/urdf/fit_10mpa.json` 已给出：

`F_nominal(s) = 280 + 122.735918491*u² + 53.969804409*u³ N`，`u=s/0.080`。

这是 9/12 MPa 目录曲线读点拟合后插值至 10 MPa 的名义模型；有效拟合范围为压缩 0–72 mm。72–80 mm 在当前运行代码中属于研究外推，不变成新增实测依据。232 mm 全伸销距、80 mm 行程沿用已确认机械尺寸。

代码核查：训练 `env.py` 加载该 JSON，`V5Control.spring_efforts()` 计算曲线并向滑块施力；`env.py` 的 reset 为启用扰动的环境采样 `spring_strength ~ U(0.9,1.1)`，干净环境为 1。当前每个环境两根气簧共用一个倍率，且随机化受扰动启用门控，不是所有阶段无条件启用。该范围是既有工程随机化范围，不能称为拟合置信区间。本轮不更改训练代码，也未核验任何远端训练进程实际加载了这一版本。

用户随后明确采用**先用预设轨迹驱动并录包，再做辨识**。下面的控制准备仅指已有的映射、静止保持及控制可用性检查，不是要求在采集前先知道电机响应参数，也不再增加一轮独立调参作为启动先决条件。沿用已部署的髋膝联合轨迹和归档控制增益采集；由实际响应决定哪些片段用于拟合，哪些问题需要下一轮定向实验。

采用以下顺序，避免把控制器增益和物理响应参数混为一谈：

1. **控制准备和诊断录包**：在完整机械总成上检查映射、静止保持和短轨迹，使 PC 位置/速度环稳定可用，排查持续自激和无效饱和。这里调整的是控制增益，不是把实机“调成没有物理滞后”。本阶段也录 bag，并版本化每次控制配置。
2. **电机/传动响应辨识**：冻结该阶段控制器，以短轨迹与有效旧 bag 识别可辨识的摩擦、阻尼、附加惯量、有效迟滞/响应等参数。髋膝仍在连杆、气簧完整安装条件下联合驱动；气簧曲线、质量和几何先固定。辨识本身就使用 real2sim 迭代，不需要等未知物理参数已经得到才开始记录。
3. **正式验证 bag**：参数候选与控制器冻结后，另录整腿参考跟踪数据；完整 687.3 s 计划可作覆盖试验，其中预留多正弦不参与调参。复现同样控制器与完整闭链，判断新参数能否预测两轴响应；如果继续按验证数据调参，该数据就转为开发集，最终验收另留数据。
4. **进入训练**：接入通过验证的执行器模型及参数，再围绕有依据的不确定性做电机域随机化；气簧使用已拟合曲线加既有/经审核的随机化。bag 是离线辨识与回放验证依据，PPO 训练使用的是经校准的仿真模型，当前没有直接用 bag 训练策略的路径。

现有包归为诊断/候选拟合材料，不因轨迹复杂就当作最终训练参数验收。是否达到第 1 步必须看响应，不能把“已提高计时容限”当成“已消除电机振荡”。

## 2. 核心实验合同：同参考、同控制器、同机械

1. 固定车体在实机支架姿态，保留整腿、轮组、闭链、气簧和重力。悬空轮无地面接触；关闭驱动不等于锁定未选侧的被动运动。
2. 同时驱动同侧髋和辅助膝两个主动轴；输入为两驱动轴坐标，而不是把辅助膝编码器读数当物理内膝角。气簧和闭链的耦合作用由动力学求解，不能再加一个任意 2×2 耦合力矩矩阵重复补偿。
3. 把 run 归档的 `q_ref/dq_ref`、初态、配置、实际时间戳和源码作为复现依据。曲线包含整圈运动，必须保持连续角及原始分支；不能用模 2π 最短误差把整圈参考变成捷径。
4. 旧包复现使用**同参考闭环仿真**：MuJoCo 以自身 q/dq 反馈执行采集版本的 RMCS 位置—速度 PI 串级。1 kHz、速度限幅、积分限幅/抗饱和、启动停留、力矩上限与调度间隔处理均相同。不能用简单位置 PD 替代旧包控制器，也不能每步把实测 q/dq 写回仿真让曲线强行重合。正式 RL 接入的同链验收则需使用上述 200 Hz PD 的独立实机数据。
5. 另设**记录力矩回放**作归因：将 bag 中实际排队发送的力矩帧按时间保持送入执行器模型，绕过 PC 控制器，比较机械响应。它帮助区分控制与机械误差，不替代同参考闭环验证。该帧仍是请求力矩，不是轴端力矩传感器测量；DM 反馈力矩也保留其驱动估计语义。
6. 先左腿、再右腿各自拟合/复核，最后做双侧复核。左右可以共享物理先验，不能先强制得到完全相同的摩擦参数。

## 3. 候选函数与参数分组

### 被动损失

运动区间可从 `tau_passive(v) = -b*v - tau_c*tanh(v/v_s)` 起步，要求 `b,tau_c >= 0`。它是平滑库仑/粘滞近似，零速时不能完整表示静摩擦承载；起动段若需要真实 stiction，可用求解器 frictionloss 或经验证的静摩擦模型。相同轴的损失只施加一次，不能再叠加同义的引擎 damping/frictionloss。

轮轴可用 `J_eff*dv/dt = tau_drive - b*v - tau_c*sign(v)` 解释运动区间，零速区另处理。没有独立力矩测量或可靠惯量先验时，先报告等效组合与不确定性，不能强行把每项都叫精确物理标定。15.8 只在 motor/output 参考端转换时使用一次。

### 执行器动态

由简单形式开始：`T*d(tau)/dt + tau = k*u(t-d)`。这里 `u` 是送入该层的力矩请求，`d` 的输入/输出时间参考端必须写清。若开发集持续出现可重复超调，再比较二阶候选；独立验收集不参与阶次选择：

`d²(tau)/dt² + 2*zeta*omega_n*d(tau)/dt + omega_n²*tau = omega_n²*k*u(t-d)`。

它们分别对应上游函数的一阶/二阶分支。速度降额、变化率限制只在相应数据可辨识时启用；不把所有自由度一次放开。主机 13.45 ms 调度停顿不能作为 USB/FOC 参数；没有硬件执行时刻或足够带宽的数据，得到的只能是约定参考端间的等效响应。当前参考到 4 Hz 也不保证能独立识别 50 Hz 内环极点。

### 气簧与刚体

沿滑块施加已拟合的本机 `F_nominal(s)`。本轮电机参数拟合固定气簧倍率为 1，不能每次仿真随机改变气簧来追逐残差。训练时再施加域随机化；如需评估气簧不确定性对电机拟合的影响，用固定的气簧参数对照组做敏感性分析并报告结果，不与电机参数一起无约束优化。不得同时在电机轴追加同一气簧的 Jacobian 投影力矩。

粘滞/密封摩擦与滞回尚未经过气簧实测辨识，暂不新增猜测值。如果按压缩/伸张方向分组的残差始终无法由当前模型解释，再单列该项，而不是为完成电机拟合强行改变已经拟合的弹性曲线。

CAD 质量、COM、惯量、关节零位先用资产与实测核对。armature 只表示模型未包含的等效转子/传动惯量，不能与 CAD 或已拟合总成惯量重复。气簧、惯量、扭矩增益和摩擦高度相关时按组固定，其不确定性必须保留。

## 4. 本项目拟合目标函数（拟新增，不是上游现成函数）

对每个拟合段 s、每个主动轴 j，比较仿真与实测响应：

`J(theta) = sum_s w_s * mean_t sum_j [rho((q_sim-q_real)/sigma_qj) + lambda_v*rho((v_sim-v_real)/sigma_vj)] + lambda_p*P(theta)`。

- `rho` 使用稳健残差损失；`sigma` 来自测量分辨率/噪声和预先声明的工程尺度，不凭某段误差大就增大尺度掩盖问题。
- 段内按真实时间积分或时间权重平均，段间独立加权，避免较长的低频段淹没差模与阶跃。拟合和留出标签由轨迹段确定，不随机拆相邻样本。
- `P(theta)` 约束物理可行域并约束偏离先验；不把参数数目多当精确。先做灵敏度/相关性检查，不能辨识的参数冻结或只给区间。
- 主要拟合 q/dq；力矩反馈用于辅助核对，未校准时不与真实轴力矩等同。饱和片段须按真实限幅回放，可作非线性验证；不能拿未裁剪的控制器请求当实际输入。
- 拟合的是 `sim vs real`，不是 `sim vs reference`。实机跟踪有误差不使数据自动作废；优化不能把实机的真实滞后和超调抹掉。
- 连续角只作一次有物理依据的初态对齐，不能逐段任意平移角度/时间以掩盖模型误差。

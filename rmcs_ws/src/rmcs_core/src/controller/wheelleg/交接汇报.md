# V5.0 轮腿 —— 站立 / 运动 / 起身 进展交接

> 日期：2026-10-16  ·  范围：`rmcs_core`（MuJoCo 仿真 + 真机传统链路）
> 结论速览：**站立、前进/转弯（stadium 3.3 m/s）、起身（自扶正 + 起身）仿真均已跑通**；
> 平衡环由 **ADRC 切换为纯参数 LQR**；新增**真机状态估计 / 站立与运动状态机 / 驱动桥**，真机传统链路已搭好骨架，待标定验收。

---

## 1. 目标与路线

- 目标：V5.0 轮腿机器人先在 MuJoCo 里**稳定站立**，再做**前进/转弯运动**，并具备**摔倒后自扶正（起身）**能力。
- 架构：**分层 SISO**——轮管外部自由度（pitch / 平移 / yaw），腿管内部姿态（腿长 L0 / 腿角 α / CoM 偏置 d / 侧倾）。
- 关键演进（相对早期版本）：
  1. 平衡/yaw 由 **ADRC（TD+ESO+NLSEF）改为纯参数 LQR 状态反馈**（`WheelLegLqrController`），消除高带宽 ESO 在真机噪声下的极限环。
  2. 引入**共享降阶腿模型**（`wheelleg_leg_model.hpp` + `leg_transmission.hpp`），仿真与真机走**同一套解算**，只有各侧的标定不同。
  3. 新增真机链路：`WheelLegStateEstimator`、`WheelLegStandStateMachine`、`WheelLegMoveStateMachine`、`WheelLegDriveBridge`。
  4. 新增两条起身路径：`WheelLegRecoveryController`（分段速率受限起身）与 `WheelLegStandupController`（照搬 RL 自扶正状态机）。
  5. 新增真机 bring-up 组件 `WheelLegBenchTestController`（5 种调试模式）。

## 2. 当前可用状态

### 2.1 仿真链路（默认 `wheelleg_sim.yaml`）

| 组件 | 作用 |
|---|---|
| `WheelLegSimulation` | MuJoCo 桥（被控对象 + 状态源 + 气簧 + 扰动/鲁棒性注入） |
| `WheelLegMotionPlanner` | 命令层：twist → S 曲线轨道 + 侧倾规划 |
| `WheelLegTrajectoryController` | 腿参考 + 姿态外环（d 环 / 起身混合 / 平衡前馈） |
| `WheelLegLqrController` → `wheelleg_balance_controller` | **pitch 平衡**：4 状态 → 共模轮力矩 |
| `WheelLegLqrController` → `wheelleg_yaw_controller` | **yaw 偏航**：yaw/角速率 → 差模轮力矩 |
| `ErrorPidController` → `wheelleg_roll_controller` | **roll 侧倾**：滚转误差 → 差动腿长 |
| `WheelLegWheelMixer` | 共模/差模 → 左右轮力矩 |

- 站立位形：`nominal_leg_length = 0.334`、`com_offset d ≈ 0`、`base_height ≈ 0.39 m`、`pitch ≈ 0`。
- 运动：`behavior: twist` 跟随 `/wheelleg/move/{velocity,yaw_rate}`；commissioning 有 `square/patrol/circle/stadium`。stadium 直道 3.3 m/s、弧道 2.5 m/s + 1.0 rad/s（半径 ≈2.5 m）可稳定跑通。
- 平衡架构要点：**平衡环独占共模轮力矩**，前进运动改由**姿态（腿角调 CoM 偏置 d）**驱动，二者不争执行器。

### 2.2 起身

- **`wheelleg_sim_recovery.yaml`**：完整链路 + `WheelLegRecoveryController`。从 `crouched` 起（底盘着地、腿收起），先 `hold_seconds=7 s` 定住起始位形，再按 **速率受限**（`l0_rate=0.03 m/s`、`shank_rate=0.5 rad/s`）把腿长/小腿角推向站立位，最后由 `alpha_r: 0→1` 平滑交棒给平衡轨迹。
- **`wheelleg_standup.yaml`**：仅 `WheelLegSimulation` + `WheelLegStandupController`，照搬 RL 自扶正状态机（`idle → SELECT → FOLD → PLANT → PREPARE → BLEND → DONE`，倒扣时 `FOLD → ORBIT → THRUST → CAPTURE → ...`），轮子用 RL 的 pitch 律（`pitch_kp/pitch_kd`）而非 ADRC/LQR。

### 2.3 真机传统链路（`wheel-leg-infantry-classic.yaml`，骨架已搭、待标定）

```
WheelLeg(hardware)
  → wheelleg_state  (StateEstimator：/wheel_leg/* + IMU → /wheelleg/state/*)
  → wheelleg_stand  (STAND 状态机：arm + 收敛 + ready)
  → wheelleg_move   (MOVE 状态机：门控 /remote/* → /wheelleg/move/*)
  → wheelleg_motion_planner → wheelleg_trajectory_controller
  → wheelleg_balance_controller / wheelleg_yaw_controller  (当前仍为 ADRC)
  → wheelleg_roll_controller (PID) → wheelleg_wheel_mixer
  → wheelleg_drive_bridge (降阶参考 → 真机关节/轮 + enable)
```

> **注意**：仿真用 LQR，真机 classic 配置目前仍写 `AdrcController`；两条平衡环可直接互换（同 topic）。仿真也已具备把 balance/yaw 换成 ADRC 的 overlay（`wheelleg_probe.yaml`）。

### 2.4 真机 bring-up（`wheel-leg-infantry-bench.yaml` + `WheelLegBenchTestController`）

单组件替代整条传统链路，`mode` 选择行为：
1. **wheel-only**：腿禁用，右摇杆 X 经 P 环命令共模轮速（测轮/前进符号）。
2. **passive**：全禁用，人工摆腿，打印解算腿形（内膝角 + 髋-轮连线角 + 长度）。
3. **pose**：内膝角闭到绝对目标（40..110°），髋-轮连线角仅小相对偏移，五次多项式爬升。
4. **attitude**：全禁用，仅统计 pitch/roll/yaw 滚动均值/std（IMU 噪声）。
5. **teleop**：左摇杆 X 积分内膝角、Y 积分髋-轮连线角，按 `teleop_side` 选择左/右/双腿。

## 3. 本轮关键修复 / 设计要点

1. **平衡环 ADRC → LQR**：ESO 高带宽（`w0=300`）放大真机 IMU 噪声并产生极限环；LQR（4 状态 `[pitch, pitch_rate, x_dot, x]`）无观测器、无非线性，增益纯参数。
2. **共享腿模型**：`LegLinkage`（六杆曲柄↔膝查表）+ `WheelLegLegModel`（前向/逆向解算）成为**唯一真值源**；真机与仿真只有 `LegCalibration` 不同（`CanonicalCalibration` = 真机 bench 标定）。
3. **膝角符号统一**：`knee_branch_sign=+1`、`knee_rel_sign=+1`（内膝角 β 为正，40..110°），修正了此前 `-1` 分支导致真机腿反装的问题。
4. **真机髋零位统一**：`hardware_hip_zero` 两侧均 `-π/2`、`hardware_crank_sign=[-1,+1]`（左/右曲柄编码器镜像）。
5. **起身的 `alpha_r` 混合**：`WheelLegTrajectoryController` 用 `/wheelleg/task/recovery`（1=平衡，0=起身）在两条腿任务间连续混合；起身时腿直接跟踪时间参数化参考（不经五次多项式重规划）。
6. **平衡使能门**：`/wheelleg/balance/enable` 只在**轮子承载**（接触法向 > 阈值）时为真；不再用旧的 `|pitch|` 门（那会让倒地后永远无法恢复）。
7. **基座速度外环**：轨迹环把轮速阻尼/位置项作为**前馈**送给平衡环（`/wheelleg/balance/feedforward`），避免与平衡环争抢轮力矩。
8. **气簧前馈模型**：`gas_spring.hpp` 给出膝力矩查表与曲柄力矩 = 膝力矩 × `dβ/dq_crank`，与 MuJoCo 桥内 `apply_gas_spring_()` 一致（站立 95° 位形约 14 Nm）。
9. **真机驱动桥**：`joint_control_mode: torque`（DM 零 Kp MIT），PD 在 `WheelLegDriveBridge` 内实现；`enable_request` 由双开关 MIDDLE + DR16 fresh + feedback fresh 门控。

## 4. 关键标定 / 数值（可复用资产）

- **整机**：`update_rate=1000 Hz`、`dt=0.001`；轮半径 `0.06`；大腿 `0.21`、小腿 `0.25005`；膝机械限位内角 `40..110°`（`0.6981..1.9199 rad`）。
- **限幅**：髋/曲柄力矩 `40 Nm`；轮（DjiMotor 输出级）`4.88 Nm`；轮电机转速上限 `49.1 rad/s`；真机轮减速比 `15.62`。
- **降阶模型质量（单腿矢状面）**：机身 `11.62`、大腿 `0.426`、小腿 `0.507`、轮 `0.40` kg；质心偏移 `thigh 0.06623`、`shank 0.15344`、`body_com 0.00918` m。
- **六杆传动**：`LegLinkage` 表 `β∈[0.326,2.586] rad ↔ c∈[-1.85,1.88]`；装配位 `kAssemblyKnee=0.787329 rad`；电机零位 = 内膝 110°。
- **canonical 标定**：`hip_sign={-1,1}`、`hip_zero={-π/2,-π/2}`、`crank_sign={-1,1}`。
- **气簧（BKB0.45-080-205）**：全伸 `0.232`、行程 `0.08`、`c0=280, c2=122.7359, c3=53.9698`。
- **LQR 平衡**：`[pitch, pitch_rate, v, x]` 增益 `[-17.6, -3.6, -3.0, -2.2]`，`u∈±4.88`。
- **LQR yaw**：`(yaw−yaw_ref, yaw_rate)` 增益 `[-10.8, -4.3]`，`u∈±8`。
- **roll PID**：`kp=-1, ki=0, kd=-50`，输出 `±0.5`。
- **ADRC（真机 classic / probe）**：平衡 `b0=20, td_r=50, eso_w0=300, k1=400, k2=100`；yaw `b0=2.32, k1=25, k2=10, β=(150,7500,0)`。

## 5. 未解决 / 待办

1. **真机标定与验收**：`真机辨识清单.md` 里的质量/质心/惯量/摩擦、零位符号、`b0`/LQR 增益尚未全部实测；真机传统链路尚未在实机验收。
2. **真机平衡环选型**：仿真用 LQR，真机 classic 配置仍为 ADRC，需统一并对比。
3. **状态估计**：`WheelLegStateEstimator` 的姿态符号、CoM、速度通道标注为 TODO，需在台架核对；无接触力传感器，`contact_normal_*` 恒 0。
4. **无电机动力学**：仿真无电流环、力矩-转速曲线、减速箱背隙/摩擦、电压跌落。
5. **接触/地形**：平地 `μ=2`，无地形/轮胎形变；弧线摩擦利用率可达 1.0，真机 `μ` 更低时更易打滑。
6. **收尾清理**：commissioning 脚手架（`lock_leg`/`fix_base*`/调试打印/`open_loop_*`/`disturbance_*`）仍在。

## 7. 复现 / 运行

构建：
```bash
cd /workspaces/RMCS/rmcs_ws
colcon build --packages-select rmcs_core --merge-install \
  --cmake-args -DRMCS_ENABLE_MUJOCO_SIM=ON
```

运行（图形）：
```bash
export DISPLAY=:0
# 站立 / 运动
ros2 launch rmcs_bringup rmcs.launch.py robot:=wheelleg_sim
# 起身
ros2 launch rmcs_bringup rmcs.launch.py robot:=wheelleg_sim_recovery
# 自扶正
ros2 launch rmcs_bringup rmcs.launch.py robot:=wheelleg_standup
```

无头运行：
```bash
export DISPLAY= WAYLAND_DISPLAY=
ros2 run rmcs_executor rmcs_executor --ros-args \
  --params-file src/rmcs_bringup/config/wheelleg_sim.yaml
```

常用开关（`wheelleg_sim` 段）：`initial_pose`（`standing|motor_zero|legs_up|crouched`）、
`hold_seconds`、`command_velocity(+_start)`、`command_acceleration`、`command_leg_length`、
`disturbance_force/start/duration`、`open_loop_wheel_torque`、`lock_leg`、`fix_base*`、
`mass_scale/inertia_scale/com_offset_y/wheel_torque_scale`、`init_pitch_deg/init_hip_delta_deg/...`。

## 8. 风险 / 注意

- 配置文件多次被脚本重写，**参数易被改坏**（历史上 `nominal_leg_length` 被改成 0.2）。
- 仿真桥是 `/wheelleg/state/*` 的**唯一生产者**（用模型真值）；真机必须用 `WheelLegStateEstimator`。
- 真机 `joint_control_mode: torque`，**PD 在 PC 侧**（`WheelLegDriveBridge`），DM 电机零 Kp MIT；参数未标定前不要上电跑整链。
- 起身/自扶正强依赖接触判定与姿态符号，**上真机前务必先过 `WheelLegBenchTestController` 的 mode 2/3**。
- 所有物理参数须先用 `真机辨识清单.md` 实测替换，再运行真机链路。

## 1. 目标与路线

- 目标：让 V5.0 轮腿机器人先在 MuJoCo 里**稳定站立**，再做**前进运动**（给定速度/加速度）。
- 路线：**方案 A（分层 SISO）** — 轮环稳 pitch、腿环撑腿型、外环做位置/速度。
- 曾放弃的方案 B（LQR/MIMO），本轮重建了部分工具但 LQR 未调通（见 §6）。

## 2. 当前可用状态

配置 `rmcs_bringup/config/wheelleg_sim.yaml` 默认 = **A4 三环站立**：

| 组件 | 作用 |
|---|---|
| `WheelLegSimulation` | MuJoCo 桥（状态/接口/commissioning/扰动） |
| `WheelLegTrajectoryController` | 腿参考 + 外环（pitch 偏置 / 位置参考） |
| `PidController` → `wheelleg_station_controller` | **位置环**：`com_x → wheel_torque_ff` |
| `AdrcController` → `wheelleg_balance_controller` | **pitch 环**：`pitch → wheel_torque` |

- `lock_leg=false`、`fix_base=false`（**base 完全自由**，不再有平面约束脚手架）。
- 站立指标（实机工况）：`L0≈0.324`、`d=com_offset≈0`、`bz≈0.384`、`pitch≈-0.007`、`roll/yaw≈0`。
- 抗扰：`disturbance_force=40N, start=3s, dur=0.2s` 时能恢复（峰值 pitch≈0.44）。
- 说明：静止平衡点 `d≈0` → `tauW≈0`（CoM 正在轮轴上方，静态不需要力矩）；主动平衡只在扰动时体现。

## 3. 本轮修复的真实 Bug（重要）

1. **自碰撞**：转换脚本给 base/大腿/小腿开了碰撞，MuJoCo 只排除父子对 → `base_link` 与其"孙"小腿重叠 1.5mm、虚假内力系数 17。
   → 修法：机器人几何放进碰撞类 2，只与地面（class 1）碰。
2. **轮驱动符号**：`L_joint3`/`R_joint3` 世界轴**都是 +x**，原代码 `wheel_torque_r = -wheel_torque`（反向自转、反作用抵消）→ 改为**同号**。
3. **`lock_leg`/`fix_base` 是"步后夹 qpos/qvel"**，不是真约束（步内自由演化）→ 改为 MJCF 里的**真 equality**（joint-lock / weld / planar carrier），由 `eq_active` 运行时开关。
4. **`eq_active` 清零把腿的闭链约束也关了** → 一解锁腿就散架（曾误判为"缺气弹簧/模型坏"）→ 修：闭链 `L_P/L_E/R_P/R_E` **始终激活**。
5. **`state_wheel_velocity` 与 `/reference/wheel_velocity` 符号相反** → 所有速度环是正反馈、必飞 → 修 `omega = +0.5(vL+vR)`。
6. **`nominal_leg_length` 被 YAML 重写改坏成 0.2**（腿塌元凶）→ 改回 0.334。
7. **`PidController` 的 `output_min/max` 只对 PID 部分限幅、前馈后加** → tilt 环用法修正。
8. `command.valid=false`（只放 sim 组件时）使 `apply_control_` 提前 return、ctrl 全清 0 → 需保留产生 valid 的控制器。

## 4. 关键标定 / 数值（可复用资产）

- **整机**：总质量 `13.702 kg`；轮半径 `0.06 m`；**摩擦力矩上限 `μMgr = 16.13 N·m`**；轮轴世界方向 `+x`；髋/曲柄力矩限 `40 N·m`。
- **腿**：2 自由度；闭链 Jacobian（髋,曲柄→L0,α）
  `J = [[-0.143, +0.143], [+0.469, +0.531]]`；约化惯量 `M_eff` 近奇异。
- **pitch 环 b0（sim 约定）**：`θ=0` 处 ≈ **+20**；随倾角强非线性（粗测 −7…−33）→ 线性 ADRC 只在小倾角准。
- **posture map（腿型↔CoM）**：`∂d/∂L0 ≈ −1.1…−1.26`（收腿→d 正/CoM 前），`∂d/∂pitch ≈ +0.26`（sim 约定）。
- **解析降阶模型**（轮式倒立摆，实测参数）：`Mb=13.30, Mw=0.40, h=0.260, Ic=0.214, Jw=7.2e-4`；
  `λ=11.6 rad/s`；`A=[[0,1,0,0],[0,0,-33,0],[0,0,0,1],[0,0,134,0]]`，`B=[[0],[5.27],[0],[-16.37]]`。
- 站立位形：`L0≈0.324, d≈0, bz≈0.384`；初始装配 `S*: L0=0.3347, α_L=1.6995, d=-0.0247`。

## 5. 未解决：前进运动（A5）

### 现象
任何"前倾/加速"指令 → **CoM 前冲（d 增大）→ 轮力矩顶满 16.13 → pitch 跑飞卡在 ~0.8 rad**。

### 已试过（全部失败）
| 手段 | 结果 |
|---|---|
| 位置斜坡（`com_x_ref` 积分速度） | 前进 0.5–1.5m 后 pitch 跑飞 |
| 速度环（轮速→轮力矩） | 正/负号都飞 |
| 速度误差→pitch 偏置（Segway 式） | 前倾到限幅、卡死 |
| 加速度→pitch 偏置 | 同上 |
| 加速度→轮前馈 | 反向、跑飞 |
| **d 闭环**（`d_ref=a·h/g`，执行器=pitch） | **`d→d_ref` 能闭上**，但 pitch 环撑不住前倾 → 跑飞 |
| **d 闭环**（执行器=腿长）+ 站环 | 收腿+加速 → 腿塌（`L0→0.1, bz=0.17`） |
| LQR（数值线性化 / 解析模型） | 都不稳（纯状态反馈消不掉稳态 CoM 偏置） |
| ESO 限幅 / 降 `w0` / b0 相关 | 无效 |

### 根因判断
**运动工况下的 pitch/CoM 平衡余量不足**：轮摩擦（16.13）+ 近直腿的几何，在"持续前倾/加速"下支撑不住；`d≈0` 时够用，一旦要产生 CoM 偏置就发散。非单点调参问题。

### 亮点（已做对但不够的部分）
- **d 环能闭上**（实测 `t=1s: d=0.0225 vs d_ref=0.0265`）——只是执行器（pitch 或腿）都撑不住。
- 速度环生成加速度（到速自动→0）逻辑已实现。

## 8. 建议的下一步

1. **先做"物理可行域"辨识（首选）**：用可信模型（含接触/腿挠度）判定——在给定 `(v, a)` 下，**当前腿型/摩擦能否支撑**（轮摩擦上限、可恢复倾角、腿的负载能力）。先判"能不能动"，再谈控制器。
2. 若可行域够：按"**d 闭环（已验证）** + 合适的执行器分配（腿/pitch 混合，保持在小倾角区）"重做运动。
3. 若可行域不足：需要**机械层面**调整（腿型/质心/传动/气弹簧建模），控制层面兜不住。
4. 收尾清理：删除 commissioning 脚手架（`lock_leg`/`fix_base*`/调试打印/`open_loop_*`/`disturbance_*`），保留 A4 站立配置作基线。

## 0. 控制律一览（一张表看懂）

| 环 | 测量（输入） | 设定（输入） | 控制量（输出） | 执行器 | 算法 |
|---|---|---|---|---|---|
| 命令规划 | `state/yaw,state/roll` | `move/velocity,move/yaw_rate` | `command/{velocity,yaw_rate,yaw,leg_length,bank,roll_bias_ff,roll_error}` | — | 加加速度限幅通道 + 侧倾规划 |
| 腿参考/外环 | `state/*`（见 §4.2） | `command/{velocity,leg_length,acceleration,yaw_rate}` | `reference/{pitch,hip_angle,knee_angle,shank_angle,wheel_velocity}` | 仿真内部腿 PD | 静态平衡解 S* + 五次多项式规划 + 步态姿态 |
| **平衡（pitch）** | `state/pitch` | `reference/pitch` | `control/wheel_torque` | 轮（共模） | **ADRC**（TD+ESO+NLSEF） |
| **偏航（yaw）** | `state/yaw` | `command/yaw` | `control/wheel_torque_diff` | 轮（差速） | **ADRC** |
| **侧倾（roll）** | `command/roll_error` | `command/roll_bias_ff`（前馈） | `control/roll_bias` | 腿长差（左右曲柄） | **PD + 前馈** |
| 轮混控 | `control/wheel_torque`,`control/wheel_torque_diff` | — | `control/wheel_torque_{l,r}` | 左右轮 | 共模优先分配 |

**一句话总结**：**轮管外部自由度（pitch / 平移 / yaw）**，**腿管内部姿态（腿型 / CoM 偏置 d / 侧倾）**。pitch、yaw 用 ADRC；侧倾用 PD+前馈；腿型用参考曲线 + 仿真内 PD。

## 1. 术语、坐标与采样

| 符号 | 含义 | 说明 |
|---|---|---|
| $q_1,q_2,q_3$ | 髋、膝(曲柄)、轮 关节角 | 电机空间 |
| $\beta$ | 等效膝角（大腿-小腿夹角） | $L_0=\sqrt{L_1^2+L_2^2-2L_1L_2\cos\beta}$ |
| $L_0=\lvert HA\rvert$ | 等效腿长（髋→轮轴） | |
| $\alpha_L$ | 绝对腿角（含 pitch） | $\alpha_L=\psi_1+\operatorname{atan2}(L_2\sin\beta,\ L_1-L_2\cos\beta)$ |
| $\gamma$ | 机身系腿角（不含 pitch） | $\gamma=\alpha_L-\theta$ |
| $\theta$ | 机身 pitch | |
| $d=(C_{veh}-A)_{fwd}$ | 质心相对轮轴的前向偏置 | 静态稳定判据 $d\to0$ |
| $r=0.06$ | 轮半径 | |
| $L_1=0.21,L_2=0.25005$ | 大腿/小腿长 | |
| $dt$ | 控制周期 | `update_rate=1000 Hz` → $dt=0.001$ s |

坐标（矢状面）：$(forward, up)=(y,z)$，轮轴向 $+x$。所有组件在 `rmcs_executor` 中**同步、同频**运行，每 tick 调用一次 `update()`。

## 2. 被控对象与降阶模型

**结构**：每腿 2 自由度（髋 $q_1$ + 曲柄 $q_c$ 经六杆驱动膝），轮 $q_3$。矢状面坐标 $(x_w,\theta,L_0,\alpha_L)$ 共 4 DOF，输入 3（髋、曲柄、轮），**欠驱动 1 维**。

| 量 | 执行器 | 权限 |
|---|---|---|
| 腿长 $L_0$ | 曲柄（经 Stephenson 六杆） | 内部姿态 |
| 腿角 $\gamma/\alpha_L$ | 髋 | 内部姿态（调 CoM $d$） |
| 平衡模态 $(x_w,\theta)$ | 轮（唯一外力矩源） | 外部自由度 |
| $x_A$/轮速 | 从动（积分态） | — |

**关键事实**：
1. **$\theta$ 欠驱动**：髋/曲柄力矩是**内力矩**，只在机身与腿之间重分配角动量；绝对 pitch 只能靠**轮-地外力矩**。
2. $d$ 与轮绝对位置无关 → "静态稳定（CoM 过轮轴）"是**相对条件**，由**腿**满足，轮无权限。
3. 轮有效力矩受**电机上限**与**摩擦锥**双重限制（见 §5.3）。

**轮式倒立摆降阶**[实测]：$\lambda=11.6$ rad/s（$\tau\approx86$ ms），是"离地多久会失稳"的时间尺度。

## 3. 控制架构总览

**激活组件**（`wheelleg_sim.yaml:4-11`）：

```
WheelLegMotionPlanner        -> wheelleg_motion_planner      命令规划
WheelLegTrajectoryController -> wheelleg_trajectory_controller 腿参考/外环
AdrcController               -> wheelleg_balance_controller  pitch 平衡
AdrcController               -> wheelleg_yaw_controller      yaw 偏航
ErrorPidController           -> wheelleg_roll_controller     roll 侧倾
WheelLegWheelMixer           -> wheelleg_wheel_mixer         轮混控
WheelLegSimulation           -> wheelleg_sim                 MuJoCo 被控对象
```

**数据流**：

```
 /wheelleg/move/{velocity,yaw_rate}
        │
        ▼
 ┌─────────────────┐  /command/{velocity,yaw_rate,yaw,leg_length,bank,roll_bias_ff,roll_error}
 │ MotionPlanner   │──────────────────────────────┬───────────────────────────┐
 └─────────────────┘                              │                           │
        ▲ state/yaw,state/roll                    ▼                           ▼
                                    ┌──────────────────────┐        ┌──────────────────┐
                                    │ TrajectoryController │        │  Yaw ADRC        │
                                    │  腿参考 + 姿态外环    │        │ yaw → tau_diff   │
                                    └──────────────────────┘        └──────────────────┘
                                        │ /reference/{pitch,hip,          │
                                        │   knee,shank,wheel_vel}         │
                                        ▼                                 │
                              ┌──────────────────┐                        │
                              │  Balance ADRC    │                        │
                              │ pitch → tau_comm │                        │
                              └──────────────────┘                        │
                                        │                                 │
                                        ▼                                 ▼
                              ┌───────────────────────────────────────────────┐
                              │              WheelMixer                        │
                              │  tau_common ± yaw_sign*tau_diff -> tau_{l,r}   │
                              └───────────────────────────────────────────────┘
                                        │ /control/{wheel_torque_l/r, roll_bias}
                                        ▼
                              ┌──────────────────┐  /reference/{hip_angle,knee_angle,wheel_velocity}
                              │ WheelLegSimulation│◄──────────────────────────────
                              │  (MuJoCo 被控对象) │  /state/* ──► 全部反馈
                              └──────────────────┘
```

**闭环归属**：

- **pitch 平衡**：`pitch(测量) − reference/pitch(设定) → wheel_torque(共模)`。
- **yaw**：`yaw − command/yaw → wheel_torque_diff`。
- **roll**：`roll_error = roll − bank → roll_bias`（差动腿长）。
- **腿型**：`reference/{hip,knee,shank}` 经仿真内 PD 跟踪（实机为电机驱动层）。
- **前向速度/位置**：**不用轮力矩闭环**，而是通过**姿态（CoM 偏置 $d$）**实现（避免与平衡环争抢轮力矩），见 §4.2。

## 4. 各环数据接口与闭环算法

### 4.1 命令规划环 `WheelLegMotionPlanner`

**输入**

| 接口 | 必需 | 含义 |
|---|---|---|
| `/wheelleg/move/velocity` | 否(=0) | 机身系前向速度目标 (m/s) |
| `/wheelleg/move/yaw_rate` | 否(=0) | 偏航角速度目标 (rad/s) |
| `/wheelleg/state/yaw` | 否 | 偏航角（用于弧线转角判定） |
| `/wheelleg/state/roll` | 否 | 侧倾角（用于 roll 误差） |

**输出**

| 接口 | 含义 |
|---|---|
| `/wheelleg/command/velocity` | S 曲线前向速度参考 (m/s) |
| `/wheelleg/command/yaw_rate` | S 曲线偏航角速度参考 (rad/s) |
| `/wheelleg/command/yaw` | 偏航角参考（角速度积分 + 弧线限幅） |
| `/wheelleg/command/acceleration` | 当前恒置 0（轨迹环自带速度 S 曲线） |
| `/wheelleg/command/leg_length` | 腿长命令（= `leg_length` 参数，当前 0.3） |
| `/wheelleg/command/bank` | 计划侧倾角 $\phi=\arctan(a_{lat}/g)$ |
| `/wheelleg/command/roll_bias_ff` | 腿部差动前馈 $k_{b2r}\cdot\phi$ |
| `/wheelleg/command/roll_error` | $roll_{meas}-\phi$（roll PD 的测量） |

**闭环算法**：

1. **加加速度限幅通道**（`step_channel_`，`wheelleg_motion_planner.cpp:108`）——每个通道对目标做加速度+加加速度双限幅：
   $$\dot r_{des}=\operatorname{clamp}\!\big(k_{ch}(goal-v),\,\pm a_{max}\big),\quad
     r\leftarrow r+\operatorname{clamp}(r_{des}-r,\,\pm j_{max}dt),\quad
     v\leftarrow v+r\,dt$$
   参数：$k_{ch}=10$、$a_{max}=1.5$、$j_{max}=4$（`channel_kp/velocity_accel/velocity_jerk`）。
2. **偏航角积分**：$yaw_{cmd}\leftarrow yaw_{cmd}+\dot{ yaw}\cdot dt$；stadium 弧线用 `yaw_setpoint_cap_` 限幅防过冲。
3. **侧倾规划**：$a_{lat}=\operatorname{clamp}(v\omega,\pm a_{lat,\lim})$，$\phi=\arctan(a_{lat}/g)$。
   - 物理可行域：$a_{lat,\lim}=0.7\cdot\min\!\big(gw/(2h)\ [\text{侧翻}],\ \mu g\ [\text{摩擦}]\big)$（`wheelleg_motion_planner.cpp:336-343`）。当前 $w=0.396,h=0.26,\mu=2$ → 侧翻主导，$a_{lat,\lim}\approx5.2$ m/s²。
   - `roll_bias_ff` $= 1.06\,\phi$；`roll_error` $= roll_{meas}-\phi$。

**行为模式**：`behavior = twist`（遥控/导航，默认）/ `square` / `patrol` / `circle` / `stadium`（当前 commissioning）。stadium：直道 $3.3$ m/s，弧道 $2.5$ m/s + $1.0$ rad/s，$3$ s 后开始。

### 4.2 腿参考与外环 `WheelLegTrajectoryController`

**输入**

| 接口 | 必需 | 用途 |
|---|---|---|
| `/wheelleg/command/velocity` | 否 | 速度命令 |
| `/wheelleg/command/leg_length` | 否 | 腿长命令 |
| `/wheelleg/command/acceleration` | 否 | 显式加速度命令 |
| `/wheelleg/command/yaw_rate` | 否 | 转向步态门（`posture_gate`，默认关闭） |
| `/wheelleg/state/wheel_velocity` | **是** | 轮速 |
| `/wheelleg/state/shank_angle`,`shank_velocity` | **是** | 小腿角/角速 |
| `/wheelleg/state/knee_angle`,`knee_velocity` | **是** | 膝角/角速 |
| `/wheelleg/state/pitch`,`pitch_velocity` | **是** | 机身 pitch |
| `/wheelleg/state/com_offset` | **是** | $d$ |
| `/wheelleg/state/leg_length` | **是** | $L_0$ |
| `/wheelleg/state/velocity`,`distance` | **是** | 机身系前向速度/里程 |
| `/wheelleg/task/alpha_bias` | 否(=0) | 外环 d 修正（**无生产者，当前恒 0**） |

**输出**

| 接口 | 含义 | 消费者 |
|---|---|---|
| `/wheelleg/reference/pitch` | pitch 设定（五次多项式） | **Balance ADRC** |
| `/wheelleg/reference/hip_angle` | 髋角参考 | 仿真桥（→ 髋电机 PD） |
| `/wheelleg/reference/knee_angle` | 膝角参考（等效 $\beta$） | 仿真桥（→ 曲柄） |
| `/wheelleg/reference/shank_angle` | 小腿角参考 | 仿真桥（关节映射） |
| `/wheelleg/reference/wheel_velocity` | 轮速参考 | 仿真桥（**仅 torque 无效时用**） |

**闭环算法**（`wheelleg_trajectory_controller.cpp:81`）：

1. **速度 S 曲线规划**（`update():105-121`）：
   $$a_{des}=\operatorname{clamp}\!\big(k_{vp}(v_{cmd}-v_{ref})-k_{vd}a_{ref},\ \pm a_{\lim}\big),\quad
     a_{ref}\leftarrow a_{ref}+\operatorname{clamp}(a_{des}-a_{ref},\pm j\,dt),\quad
     v_{ref}\leftarrow v_{ref}+a_{ref}dt$$
   参数 $k_{vp}=10,k_{vd}=2,a_{\lim}=1.5,j=4$。输出 $v_{ref}$、$a_{planned}=a_{ref}$。
2. **机身系里程参考**：$s_{ref}\leftarrow s_{ref}+v_{ref}dt$。
3. **外环位置/速度 → 加速度**（`:161`）：门控 $g=$（`posture_gate_enabled=false` → 1）
   $$a_{outer}=g\big(k_v(v_{ref}-v_{meas})+k_x(s_{ref}-s_{meas})\big),\quad k_v=k_x=0.5$$
   $$a_{cmd}=a_{explicit}+a_{planned}+a_{outer}$$
4. **静态平衡解 $S^*$**（`solve_target_`，`:383`）：给定腿长命令，
   $$\cos\beta=\frac{L_1^2+L_2^2-L_0^2}{2L_1L_2},\quad \beta=s_{branch}\arccos(\cos\beta),\quad s_{branch}=-1$$
   $$a_1=m_bL_1+m_1(L_1-d_1),\qquad a_2=(m_b+m_1)L_2+m_2(L_2-d_2)$$
   $$P=-a_1\sin\beta,\quad Q=a_1\cos\beta-a_2,\quad \Gamma=\sqrt{P^2+Q^2}$$
   $$\phi=\arcsin\!\big(m_b\,c_b/\Gamma\big)-\operatorname{atan2}(Q,P),\qquad \alpha^*=\pi-\beta-\phi$$
   其中 $c_b$ 为机身质心前向偏移。输出 `target.{leg_length,beta,shank,hip,wheel_velocity}`。
5. **步态/姿态（$d$ 外环）**（`:189-202`），把"要产生的加速度"翻译成 CoM 偏置 $d^*=a_{cmd}h/g$，用**等效腿角**为主执行：
   $$d^*=\frac{a_{cmd}h}{g},\quad e_d=d^*-d$$
   $$gait_{dhip}=g\big(k_{\theta ff}d^*+k_{v}e_d\big),\qquad gait_{dl}=g\big(k_{Lff}d^*+k_{dp}e_d\big)$$
   参数：$k_{\theta ff}=3.85$ rad/m，$k_v=2.0$，$k_{Lff}=-0.909$，$k_{dp}=-0.5$。腿长微调量经 `solve_target_` 转成 $gait_{dknee},gait_{dshank}$。
6. **静态稳定守卫**（`:207`）：若 $\lvert d\rvert>d_{max}$（当前 100，禁用）→ 冻结腿长、`feasible=false`。
7. **规划重启**（`:220`）：仅在**腿长命令变化**（超过 $\varepsilon=10^{-4}$）时重启五次多项式；速度命令变化**不**重启（否则会冻结 pitch 参考、关掉平衡环）。
8. **五次多项式过渡**（`Quintic`，`:266`）：pitch、shank、knee 各自从当前状态 $C^2$ 过渡到目标，pitch 过渡时间 0.15 s，其余 1.5 s；轮速参考直接用 S 曲线的 $v_{ref}$。
9. **发布**（`publish_reference_`）：
   - 腿动耦合修正 $x_e$：$x_e=L_1\cos(\beta+\phi)-L_2\cos\phi$，
     $$\omega_{ref}=\big(v_{ref}+\dot x_e\big)/r$$
   - `reference/pitch` $=pitch_{plan}$。
   - `reference/shank` $=shank_{plan}+gait_{dshank}$，`reference/knee` $=\beta_{plan}+gait_{dknee}$。
   - `reference/hip` $=\pi-pitch_{ref}-knee_{pub}-shank_{pub}+\alpha_{bias}+gait_{dhip}$。

### 4.3 平衡环 `AdrcController` → `wheelleg_balance_controller`

**输入**

| 接口 | 含义 |
|---|---|
| `/wheelleg/state/pitch` | 测量 $\theta$（`measurement`） |
| `/wheelleg/reference/pitch` | 设定 $\theta^*$（`setpoint`） |

**输出**

| 接口 | 含义 |
|---|---|
| `/wheelleg/control/wheel_torque` | 共模轮力矩 (Nm) |

**算法**（`adrc_controller.cpp` + `td.hpp/eso.hpp/nlesf.hpp`），被控量建模为二阶：
$$\ddot\theta=f+b_0 u,\qquad u=\tau_{wheel},\quad b_0=20$$

- **TD（跟踪微分器）**：$r=50$，$h=dt$
  $$fh=fhan(x_1-\theta^*,\,x_2,\,r,\,h),\quad x_1\leftarrow x_1+hx_2,\quad x_2\leftarrow x_2+h\,fh$$
- **ESO（扩张状态观测器）**：$w_0=300$ → $\beta_1=3w_0=900,\ \beta_2=3w_0^2=2.7\times10^5,\ \beta_3=w_0^3=2.7\times10^7$
  $$e=z_1-\theta,\quad
    z_1\leftarrow z_1+h(z_2-\beta_1 e),\quad
    z_2\leftarrow z_2+h(z_3+b_0u-\beta_2 e),\quad
    z_3\leftarrow z_3+h(-\beta_3 e)$$
  $z_3$ 汇总模型误差与外力扰动。
- **NLSEF（非线性状态误差反馈）**：$e_1=x_1-z_1,\ e_2=x_2-z_2$，$k_1=400,\ k_2=100,\ \alpha_1=0.75,\ \alpha_2=0.7,\ \delta=0.02$
  $$u_0=k_1 fal(e_1,\alpha_1,\delta)+k_2 fal(e_2,\alpha_2,\delta),\qquad
    u=\big(u_0-z_3\big)/b_0$$
  $$fal(e,\alpha,\delta)=\begin{cases}e/\delta^{1-\alpha}&\lvert e\rvert\le\delta\\ \lvert e\rvert^\alpha\operatorname{sign}(e)&\lvert e\rvert>\delta\end{cases}$$
- **限幅**：$u\leftarrow\operatorname{clamp}(u,\pm4.88)$。
- 无前馈。`disable_output` 在测量/设定非有限时输出 NaN 并复位。

**说明**：$b_0$ 随倾角强非线性（实测 $-7\ldots-33$），故线性/常 $b_0$ ADRC 只在小倾角准；大倾角 $z_3$ 易发散（这是已知风险，见 §8）。

### 4.4 偏航环 `AdrcController` → `wheelleg_yaw_controller`

**输入**：`/wheelleg/state/yaw`（measurement）、`/wheelleg/command/yaw`（setpoint）。
**输出**：`/wheelleg/control/wheel_torque_diff`（差速轮力矩 Nm）。

**算法**：同 ADRC 结构，模型 $\ddot\psi=f+b_0u$，$b_0=2.32$：

- TD：$r=50$。
- ESO：`eso_auto_beta=false`，$\beta_1=150,\beta_2=7500,\beta_3=0$ → **$z_3\equiv0$**（不做扰动估计，退化为二阶观测器 + 比例微分反馈）。
- NLSEF：$k_1=25,\ k_2=10,\ \alpha_1=0.75,\alpha_2=0.7,\delta=0.02$，$u=u_0/b_0$。
- 限幅：$\pm8$。

### 4.5 侧倾环 `ErrorPidController` → `wheelleg_roll_controller`

**输入**

| 接口 | 含义 |
|---|---|
| `/wheelleg/command/roll_error` | 测量 $=roll_{meas}-bank$ |
| `/wheelleg/command/roll_bias_ff` | 前馈 $=1.06\cdot bank$ |

**输出**：`/wheelleg/control/roll_bias`（左右曲柄差动偏置，rad）。

**算法**（`pid_calculator.hpp:32`，对误差，非标准带 $dt$ 形式）：
$$u_{pid}=k_p e+k_i\!\int e+k_d\,\Delta e,\quad
  e<-1\ \text{或}\ e>1\Rightarrow I\leftarrow0$$
$$\text{control}=\operatorname{clamp}\big(ff+u_{pid},\,\pm0.5\big)$$
参数：$k_p=-1,\ k_i=0,\ k_d=-50$，积分限 $\pm0.5$，积分分离 $\pm1.0$。**负增益**是因为 `roll_bias` 对 roll 的静态增益为负方向。

**作用路径**：`roll_bias` 经仿真桥转成左右曲柄目标差动（左 $+bias$、右 $-bias$）→ 差动腿长 → 机身侧倾。

### 4.6 轮混控 `WheelLegWheelMixer`

**输入**：`/wheelleg/control/wheel_torque`（共模）、`/wheelleg/control/wheel_torque_diff`（差速）。
**输出**：`/wheelleg/control/wheel_torque_l`、`/wheelleg/control/wheel_torque_r`。

**算法**（`wheelleg_wheel_mixer.cpp:55`，共模优先分配）：
```
common = clamp(common, ±L)            # L = wheel_torque_limit = 4.88
headroom = L - |common|
diff   = clamp(yaw_sign * diff, ±headroom)   # yaw_sign = -1
tau_l = common + diff
tau_r = common - diff
```
若 common 非有限 → 输出 NaN（桥回落到零力矩路径）。

## 5. 执行层：仿真桥 `WheelLegSimulation`（实机对应硬件层）

### 5.1 状态映射（输出 `/wheelleg/state/*`）

`publish_state_`（`wheelleg_simulation.cpp:1116`）**全部由 MuJoCo 真值**换算：

### 5.2 控制映射（输入 `reference/*`、`control/*` → 关节力矩）

`apply_control_`（`:831`）：

1. **参考模式**（本配置生效，腿走参考角）：
   - 髋目标：$q_1^*=\operatorname{wrap}(s_{hip}(\alpha^*-h_0))$（$s_{hip}=-1,h_0=\pi$）。
   - 曲柄目标：由膝参考经 Stephenson 六杆查表 $c=f(\beta)$，$q_c^*=c-c_{asm}+q_1$。
   - **腿 PD + 重力前馈**：$\tau_{hip}=k_p^{hip}(q_1^*-q_1)-k_d^{hip}\dot q_1+\tau_g$，曲柄同理（$k_p=250/150,k_d=6/2$；重力用解析式或 `qfrc_bias`）。
2. **力矩模式**：`leg_torque_valid`/`per_leg_torque_valid` 时直通（当前未用）。
3. **轮力矩**：`per_leg_wheel_valid` > `torque_valid` > 速度伺服三级。
4. **roll_bias**：参考模式下左曲柄 $+bias$、右 $-bias$。

### 5.3 轮摩擦上限（**当前实现**）

每步用**上一步接触求解的真实法向力**计算动态摩擦上限：
$$\tau_{w,\lim}=\begin{cases}\text{motor limit (47.3)} & N\le\varepsilon\ (\text{离地，无摩擦})\\
\min\!\big(47.3,\ \mu N(t)\,r\big)& N>\varepsilon\end{cases}$$
其中 $\mu N(t)$ 取自接触：$\sum_i \mu_i N_i$（`contact.friction[0]*normal`），$\varepsilon=10^{-3}$ N。
> 旧实现用常数 $\mu Mg r=16.13$（静重、整机分配）——非法物理；现改为逐轮、逐时刻的 $\mu N(t)r$。**直行/站立零影响，弧线滑移下降**（详见 §9）。

## 6. 闭环回路分析

| 回路 | 开环对象 | 带宽/增益 | 反馈量 | 限幅 |
|---|---|---|---|---|
| pitch 平衡 | $\ddot\theta=f+20\tau_w$ | TD $r=50$；ESO $w_0=300$；$k_1{=}400,k_2{=}100$ | pitch, pitch_rate（ESO） | $\pm4.88$ |
| yaw | $\ddot\psi=f+2.32\tau_d$ | ESO $\beta{=}(150,7500)$；$k_1{=}25,k_2{=}10$ | yaw, yaw_rate | $\pm8$ |
| roll | $roll\approx$ 静态增益 × `roll_bias` | $k_p{=}-1,k_d{=}-50$ | roll error | $\pm0.5$ |
| 腿型 | 关节+六杆+PD | 髋 250/6，曲柄 150/2 | 关节角 | 髋40/曲柄40 |
| 速度/位置 | 姿态$d$→腿角/腿长（非轮） | $k_v{=}k_x{=}0.5$，$k_{\theta ff}{=}3.85$，$k_v{=}2.0$ | $v,s,d$ | 腿长 0.22–0.45 |

**外环为什么不用轮**：平衡环独占共模轮力矩；前向运动改由**姿态（CoM 偏置）**驱动，二者不争执行器。这是 A5 运动能跑通的关键架构选择。

**耦合**：
- 腿动 → pitch：腿变形/质心移动扰动 $\theta$，由平衡环吸收。
- 轮矩反作用 → 腿：进腿的重力/负载前馈（当前仅静态重力，动态项 [待定]）。
- 侧倾 → 腿长差：`roll_bias` 只改曲柄目标，间接差动腿长。

## 9. 标定、调试与 sim2real 注意

**标定/调试**：
- 关节零位/符号：`hip_sign,hip_zero,knee_zero_{l,r},state_*_sign`（仿真一致；实机须重标）。
- 重力前馈：`gravity_ff_analytic`（解析）vs `qfrc_bias`（模型真值）。**实机必须解析式**。
- 摩擦观测 [+新增]：`/wheelleg/state/{contact_normal,slip,friction_utilization,friction_torque_limit,wheel_torque}_{l,r}`；开环 CSV 用 `config/wheelleg_probe.yaml` overlay。

**sim2real 缺口**（不含电机-单片机通信）：
1. **无真机硬件组件**（仅 `plugins_mujoco.xml`）。
2. **腿 PD 在仿真内部**（`hip_kp/crank_kp`）——实机须由电机驱动层实现。
3. **无电机动力学**：无电流环、力矩-转速曲线（反电动势）、减速箱背隙/摩擦、电压跌落。
4. **状态多为模型真值**：`com_*`、`velocity`、`distance` 等真机需估计（IMU/编码器/里程计）。
5. **参数全来自 MJCF**：质量/质心/惯量/b0/腿几何须系统辨识；$b_0$ 强非线性。
6. **接触/地面**：平地 $\mu=2$，无地形/轮胎形变；弧线摩擦利用率已达 1.0（实测），$\mu$ 降真实值后转弯更易打滑。
7. **反作用轮效应可忽略**：机身 99.7% 时间至少一轮接地；单轮离地均 1.7–2.6 ms，靠另一轮与 $\tau\approx86$ ms 的失稳时间常数兜住。
8. **高带宽 ADRC**（$w_0=300$）会放大真机 IMU 噪声，须滤波/降带宽。

**实测性能基线** [实测]：
- 站立：$L_0\approx0.29\text{–}0.33$，$d\approx0$，$pitch\approx0$。
- stadium 直行 $3.3$ m/s：摩擦利用率 $\le0.43$，滑移 $\approx0.03$ m/s（纯滚动）。
- 弧道：摩擦利用率峰值 $1.0$，入弯右轮瞬时离地；动态摩擦限幅后滑移显著下降且保持稳定。
- 抗扰：$40$ N、$0.2$ s 脉冲可恢复（历史 A4 基线）。

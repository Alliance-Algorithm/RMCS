## 0. 控制律一览（一张表看懂）

| 环 | 测量（输入） | 设定（输入） | 控制量（输出） | 执行器 | 算法 |
|---|---|---|---|---|---|
| 命令规划 | `state/yaw,state/roll` | `move/velocity,move/yaw_rate` | `command/{velocity,yaw_rate,yaw,acceleration,leg_length,bank,roll_bias_ff,roll_error}` | — | 加加速度限幅通道 + 侧倾规划 |
| 腿参考/外环 | `state/*`（见 §4.2） | `command/{velocity,leg_length,acceleration,yaw_rate}` + `task/*` | `reference/{pitch,hip_angle,knee_angle,shank_angle,wheel_velocity}`，`balance/{enable,feedforward}` | 仿真内部腿 PD / 真机驱动桥 | 静态平衡解 S* + 2-DOF 位形 + 五次多项式 + 步态姿态 |
| **平衡（pitch）** | `state/{pitch,pitch_velocity,velocity,distance}` | — | `control/wheel_torque` | 轮（共模） | **LQR**（4 状态状态反馈） |
| **偏航（yaw）** | `state/{yaw,yaw_rate}` | `command/yaw` | `control/wheel_torque_diff` | 轮（差速） | **LQR** |
| **侧倾（roll）** | `command/roll_error` | `command/roll_bias_ff`（前馈） | `control/roll_bias` | 腿长差（左右曲柄） | **PD + 前馈** |
| 轮混控 | `control/{wheel_torque,wheel_torque_diff}` | — | `control/wheel_torque_{l,r}` | 左右轮 | 共模优先分配 |
| 真机状态估计 | `/wheel_leg/*` + IMU | — | `state/pitch/roll/yaw,leg_length,knee,shank,com_offset,wheel_velocity,...` | — | 六杆正解 + analytic CoM |
| 真机站立/运动层 | 遥控器 + `state/*` | — | `stand/{armed,phase,ready}`、`move/{velocity,yaw_rate}` | — | 顶层状态机（门控） |
| 标定/调试 | 关节编码器/IMU/轮速 | `calib/mode` | `calib/{joint,wheel}/torque` | 腿 + 轮 | `WheelLegCalibController`（mode 1/2/4/5），经驱动桥直通 |

**一句话总结**：**轮管外部自由度（pitch / 平移 / yaw）**，**腿管内部姿态（腿型 / CoM 偏置 d / 侧倾）**。
pitch、yaw 用 **LQR**；侧倾用 **PD+前馈**（stand 调试时增益置 0）；腿型用**共享六杆模型解算 + 驱动桥 PD**。

## 1. 术语、坐标与采样

| 符号 | 含义 | 说明 |
|---|---|---|
| $q_1,q_c,q_3$ | 髋、曲柄、轮 关节角 | 电机空间（$q_c$ 经 Stephenson 六杆驱动膝） |
| $\beta$ | 内膝角（大腿-小腿夹角） | 伸直 $=\pi$，机械限位 $40..110^\circ$ |
| $L_0=\lvert HA\rvert$ | 等效腿长（髋→轮轴） | |
| $\alpha$ | 降阶髋角 | 机身系腿角 |
| $\varphi$ | 小腿角（shank） | $\varphi=\pi-\beta-\alpha$ |
| $\theta$ | 机身 pitch | 前倾为正 |
| $d=(C_{veh}-A)_{fwd}$ | 质心相对轮轴的前向偏置 | 静态稳定判据 $d\to0$ |
| $r$ | 轮半径 $=0.06$ | |
| $L_1,L_2$ | 大腿/小腿 $=0.21,0.25045$ | |
| $dt$ | 控制周期 | `update_rate=1000 Hz` → $dt=0.001$ s |

坐标（矢状面）：$(forward, up)=(x,z)$。全部组件在 `rmcs_executor` 中**同步、同频**运行，每 tick 调用一次 `update()`。
详细几何/质心定义见 `执行路线1_数学解析.md`。

## 2. 被控对象与降阶模型

**结构**：每腿 2 自由度（髋 $q_1$ + 曲柄 $q_c$ 经六杆驱动膝），轮 $q_3$。矢状面坐标 $(x_w,\theta,L_0,\alpha_L)$ 共 4 DOF，输入 3（髋、曲柄、轮），**欠驱动 1 维**。

| 量 | 执行器 | 权限 |
|---|---|---|
| 腿长 $L_0$ | 曲柄（经 Stephenson 六杆） | 内部姿态 |
| 腿角 $\alpha/\alpha_L$ | 髋 | 内部姿态（调 CoM $d$） |
| 平衡模态 $(x_w,\theta)$ | 轮（唯一外力矩源） | 外部自由度 |
| $x_A$/轮速 | 从动（积分态） | — |

**关键事实**：

1. **$\theta$ 欠驱动**：髋/曲柄力矩是**内力矩**，只在机身与腿之间重分配角动量；绝对 pitch 只能靠**轮-地外力矩**。
2. $d$ 与轮绝对位置无关 → "静态稳定（CoM 过轮轴）"是**相对条件**，由**腿**满足，轮无权限。
3. 轮有效力矩受**电机上限**与**摩擦锥**双重限制（见 §5.3）。

**共享降阶模型**（`wheelleg_leg_model.hpp` + `leg_transmission.hpp`）是**唯一真值源**：仿真与真机只有
`LegCalibration` 不同，解算完全一致。**轮式倒立摆降阶**[实测]：$\lambda\approx11.6$ rad/s（$\tau\approx86$ ms），
是"离地多久会失稳"的时间尺度。

```

        │
        ▼
 ┌─────────────────┐  /command/{velocity,yaw_rate,yaw,acceleration,leg_length,bank,roll_bias_ff,roll_error}
 │ MotionPlanner   │──────────────────────────────┬───────────────────────────┐
 └─────────────────┘                              │                           │
        ▲ state/yaw,state/roll                    ▼                           ▼
                                    ┌──────────────────────┐        ┌──────────────────┐
                                    │ TrajectoryController │        │  Yaw LQR         │
                                    │  腿参考 + 姿态外环    │        │ yaw → tau_diff   │
                                    └──────────────────────┘        └──────────────────┘
                                        │ /reference/{pitch,hip,          │
                                        │   knee,shank,wheel_vel},        │
                                        │ /balance/{enable,feedforward}   │
                                        ▼                                 │
                              ┌──────────────────┐                        │
                              │  Balance LQR     │                        │
                              │ [pitch,rate,v,x] │                        │
                              └──────────────────┘                        │
                                        │                                 │
                                        ▼                                 ▼
                              ┌───────────────────────────────────────────────┐
                              │              WheelMixer                        │
                              │  tau_common ± yaw_sign*tau_diff -> tau_{l,r}   │
                              └───────────────────────────────────────────────┘
                                        │ /control/{wheel_torque_l/r, roll_bias}
                                        ▼
                              ┌──────────────────┐  /reference/{hip_angle,knee_angle,wheel_velocity}
                              │ SimBridge /      │◄──────────────────────────────
                              │ DriveBridge      │
                              └──────────────────┘
```

**闭环归属**：

- **pitch 平衡**：`u = Σ gain_i·(state_i − setpoint_i) → wheel_torque(共模)`。
- **yaw**：`yaw − command/yaw → wheel_torque_diff`。
- **roll**：`roll_error = roll − bank → roll_bias`（差动腿长）。
- **腿型**：`reference/{hip,knee,shank}` 经仿真内 PD（实机为驱动桥 PD）跟踪。
- **前向速度/位置**：**不用轮力矩闭环**，通过**姿态（CoM 偏置 $d$）**实现（避免与平衡环争抢轮力矩），见 §4.2。

## 4. 各环数据接口与闭环算法

### 4.1 命令规划环 `WheelLegMotionPlanner`

**输入**：`/wheelleg/move/velocity`（否=0, m/s，机身系）、`/wheelleg/move/yaw_rate`（否=0, rad/s）、
`/wheelleg/state/yaw`、`/wheelleg/state/roll`。

**输出**：

| 接口 | 含义 |
|---|---|
| `/wheelleg/command/velocity` | S 曲线前向速度参考 (m/s) |
| `/wheelleg/command/yaw_rate` | S 曲线偏航角速度参考 (rad/s) |
| `/wheelleg/command/yaw` | 偏航角参考（角速度积分 + 弧线限幅） |
| `/wheelleg/command/acceleration` | 当前恒置 0（轨迹环自带速度 S 曲线） |
| `/wheelleg/command/leg_length` | 腿长命令（= `leg_length` 参数，当前 0.334） |
| `/wheelleg/command/bank` | 计划侧倾角 $\phi=\arctan(a_{lat}/g)$ |
| `/wheelleg/command/roll_bias_ff` | 腿部差动前馈 $k_{b2r}\cdot\phi$ |
| `/wheelleg/command/roll_error` | $roll_{meas}-\phi$（roll PD 的测量） |

**闭环算法**（`wheelleg_motion_planner.cpp:59`）：

1. **加加速度限幅通道**（`step_channel_`, `:110`）——每个通道对目标做加速度+加加速度双限幅：
   $$\dot r_{des}=\operatorname{clamp}\!\big(k_{ch}(goal-v),\,\pm a_{max}\big),\quad
     r\leftarrow r+\operatorname{clamp}(r_{des}-r,\,\pm j_{max}dt),\quad
     v\leftarrow v+r\,dt$$
   参数：$k_{ch}=10$、$a_{max}=1.5$、$j_{max}=4$（速度）；$a=6.28$、$j=40$（yaw）。
2. **偏航角积分**：$yaw_{cmd}\leftarrow yaw_{cmd}+\dot{ yaw}\cdot dt$；stadium 弧线用 `yaw_setpoint_cap_` 限幅防过冲。
3. **侧倾规划**：$a_{lat}=\operatorname{clamp}(v\omega,\pm a_{lat,\lim})$，$\phi=\arctan(a_{lat}/g)$。
   - 物理可行域：$a_{lat,\lim}=0.7\cdot\min\!\big(gw/(2h)\ [\text{侧翻}],\ \mu g\ [\text{摩擦}]\big)$（`:339-346`）。
     仿真 $w=0.3966,h=0.26,\mu=2$ → 侧翻主导，$a_{lat,\lim}\approx5.2$ m/s²。
   - `roll_bias_ff` $= 1.06\,\phi$；`roll_error` $= roll_{meas}-\phi$。
4. **前进方向符号**：`command/velocity = velocity_sign · v`（仿真/真机均为 $-1$，机身系镜像）。

**行为模式**：`behavior = twist`（遥控/导航，默认）/ `square` / `patrol` / `circle` / `stadium`。
stadium：直道 3.3 m/s、弧道 2.5 m/s + 1.0 rad/s（半径 ≈2.5 m），3 s 后开始。

### 4.2 腿参考与外环 `WheelLegTrajectoryController`

**输入**：`command/{velocity,leg_length,acceleration,yaw_rate}`、`task/{alpha_bias,shank,leg_length,recovery}`、
`state/{wheel_velocity,shank_angle,shank_velocity,knee_angle,knee_velocity,pitch,pitch_velocity,com_offset,leg_length,velocity,distance,contact_normal_l/r}`。

**输出**：`reference/{pitch,hip_angle,knee_angle,shank_angle,wheel_velocity}`、`balance/{enable,feedforward}`。

**闭环算法**（`wheelleg_trajectory_controller.cpp:78`）：

1. **速度 S 曲线规划**（`:105-121`）：
   $$a_{des}=\operatorname{clamp}\!\big(k_{vp}(v_{cmd}-v_{ref})-k_{vd}a_{ref},\ \pm a_{\lim}\big),\quad
     a_{ref}\leftarrow a_{ref}+\operatorname{clamp}(a_{des}-a_{ref},\pm j\,dt),\quad
     v_{ref}\leftarrow v_{ref}+a_{ref}dt$$
   参数 $k_{vp}=10,k_{vd}=2,a_{\lim}=1.5,j=4$。输出 $v_{ref}$、$a_{planned}=a_{ref}$。
2. **机身系里程参考**：$s_{ref}\leftarrow s_{ref}+v_{ref}dt$。
3. **外环位置/速度 → 加速度**（`:153`）：门控 $g=$（`posture_gate_enabled=false` → 1）
   $$a_{outer}=g\big(k_v(v_{ref}-v_{meas})+k_x(s_{ref}-s_{meas})\big),\quad k_v=k_x=0.5$$
   $$a_{cmd}=a_{explicit}+a_{planned}+a_{outer}$$
4. **静态平衡解 $S^*$**（`solve_target_`, `:451`）：见 `执行路线1_数学解析.md` §6，输出
   `Target{leg_length,beta,shank,hip,wheel_velocity,feasible}`。
5. **二维位形 `solve_pose_`**（`:520`）：把 shank 角 $\varphi$ 作为**独立输入**，覆盖整个工作空间。
6. **起身混合（`alpha_r`）**（`:176`，接口保留）：`task/recovery` ∈ [0,1]（1=平衡，0=起身）；
   $$L_0\leftarrow \alpha_r L_0^{bal}+(1-\alpha_r)L_0^{rec},\qquad
     \varphi\leftarrow \alpha_r\varphi^{bal}+(1-\alpha_r)\varphi^{rec}$$
   当前 stand/sim 图**没有** `task/*` 生产者（`WheelLegRecoveryController` 已在清理中删除），故恒 `alpha_r=1`。
7. **步态/姿态（$d$ 外环）**（`:212`），把要产生的加速度翻译成 CoM 偏置 $d^*=a_{cmd}h/g$：
   $$d^*=\frac{a_{cmd}h}{g},\quad e_d=d^*-d$$
   $$gait_{hip}=\alpha_r\,g\big(k_{\theta ff}d^*+k_v e_d\big),\qquad
     gait_{dL}=\alpha_r\,g\big(k_{Lff}d^*+k_{dp}e_d\big)$$
   参数：$k_{\theta ff}=3.85$ rad/m，$k_v=2.0$，$k_{Lff}=-0.909$，$k_{dp}=-0.5$。腿长微调经 `solve_target_` 转成 $gait_{dknee},gait_{dshank}$。
8. **静态稳定守卫**（`:235`）：仅当 `alpha_r=1` **且**轮子承载 **且** $|d|>d_{max}$（当前 100，禁用）→ 冻结腿长、`feasible=false`。
9. **平衡使能 / 基座速度前馈**（`:245`）：
   - `drive_enabled = armed && !hold && tilt_ok && dm_ready`，发布 `/wheelleg/drive/enabled`；
   - `balance_enabled = drive_enabled && (无遥控 || left=MIDDLE && right=UP)`，发布
     `/wheelleg/drive/balance_enabled`（LQR 的 `enable` 用它；避免 LQR→mixer→bridge 依赖环）；
   - `/wheelleg/balance/enable` = `supported && drive_enabled` 仍会发布，但 **LQR 不消费**；
     估计器无力传感器，`contact_normal_*` 为 **NaN**；`supported` 把 NaN 视为“承载”。
   - `balance/feedforward` 仅 ADRC 使用；LQR 无前馈输入。
10. **规划重启**（`:279`）：在 `!initialized_`（首次/失能/状态恢复）或**腿长命令变化**超过
    `leg_length_epsilon=1e-2` 时重启五次多项式；速度命令变化**不**重启。`startup_settle_s`（默认 0）
    可在使能后先钉住实测位姿一段时间，用于避开启动瞬态。
11. **五次多项式过渡**（`Quintic`, `:329`）：pitch、shank、knee 各自从当前状态 $C^2$ 过渡到目标，
    pitch 过渡 0.15 s，shank/knee 默认 1.5 s（当前 sim 配置为 4.0 s）；轮速参考用 S 曲线的 $v_{ref}$。
12. **发布**（`publish_reference_`, `:562`）：
    - 腿动耦合修正 $x_e=L_1\cos(\beta+\varphi)-L_2\cos\varphi$，$\omega_{ref}=(v_{ref}+\dot x_e)/r$。
    - `reference/pitch` $=pitch_{plan}$（当前图 `alpha_r=1`；接口仍支持起身时保持实测 pitch）。
    - `reference/shank` $=\varphi_{plan}+gait_{dshank}$，`reference/knee` $=\beta_{plan}+gait_{dknee}$。
    - `reference/hip` $=\pi-\theta_{ref}-\beta_{pub}-\varphi_{pub}+\alpha_{bias}+gait_{hip}$。
    - 每腿单独发布 `/wheelleg/reference/{hip,knee,shank}_angle_l/r`；驱动桥优先用逐腿量，
      缺失时回落到上面的平均 topic。

> **注意**：LQR 的 `enable` 已接 `/wheelleg/drive/balance_enabled`；`/wheelleg/balance/enable` 与
> `/wheelleg/balance/feedforward` 没有 LQR 消费者（仅 ADRC 有 `feedforward` 参数，当前无配置使用）。
> `/wheelleg/task/alpha_bias` 无生产者，恒 0。

### 4.3 平衡环 `WheelLegLqrController` → `wheelleg_balance_controller`

**输入**：`state/pitch`、`state/pitch_velocity`、`state/velocity`、`state/distance`（可选 `setpoint_*`）。
**输出**：`control/wheel_torque`（共模轮力矩 Nm）。

**算法**（`wheel_leg_lqr_controller.cpp:64`）：纯参数状态反馈，无观测器/无非线性：
$$\boxed{\;u=\operatorname{clamp}\Big(\sum_i g_i\,(x_i-x_i^*),\;u_{min},u_{max}\Big)\;}$$
展开（仿真参数）：
$$u=g_{x}\,\theta+g_{y}\,\dot\theta+g_{z}\,v+g_{w}\,x$$
$g=[-17.6,\,-3.6,\,-3.0,\,0.0]$（当前 stand/sim：`gain_w=0`，**不做位置保持**；旧基线为 $-2.2$），
`noise_x=0.001`（可选输入噪声注入），$u\in\pm4.88$。`enabled=true`，`enable=/wheelleg/drive/balance_enabled`。

> 选 LQR 的原因：ESO 高带宽（$w_0=300$）放大真机 IMU 噪声产生极限环；LQR 无观测器、增益即参数，便于调。

**备份（ADRC）**：`AdrcController` 代码与插件保留，但 classic/probe 两个 yaml 已删除，当前无配置使用：
$$\ddot\theta=f+b_0u,\quad b_0=20,\ \text{TD }r=50,\ \text{ESO }w_0=300\ (\beta_1=3w_0,\beta_2=3w_0^2,\beta_3=w_0^3),$$
NLSEF $k_1=400,k_2=100$，$u\in\pm4.88$。无前馈（除非配置 `feedforward`）。

### 4.4 偏航环 `WheelLegLqrController` → `wheelleg_yaw_controller`

**输入**：`state/yaw`、`state/yaw_rate`，`setpoint_x=/wheelleg/command/yaw`。
**输出**：`control/wheel_torque_diff`（差速轮力矩 Nm）。

**算法**：同一 LQR 结构，
$$u=g_x(\psi-\psi^*)+g_y\dot\psi,\qquad g=[-10.8,\,-4.3],\quad u\in\pm8.0.$$

**备份（ADRC）**：$\ddot\psi=f+2.32u$，TD $r=50$，ESO `auto_beta=false`，$\beta=(150,7500,0)$ → **$z_3\equiv0$**
（退化为二阶观测器），$k_1=25,k_2=10$，$u\in\pm8$。

### 4.5 侧倾环 `ErrorPidController` → `wheelleg_roll_controller`

**输入**：`command/roll_error`（测量 $=roll_{meas}-bank$）、`command/roll_bias_ff`（前馈 $=1.06\cdot bank$）。
**输出**：`control/roll_bias`（左右曲柄差动偏置，rad）。

**算法**（`pid_calculator.hpp`，对误差，非标准带 $dt$ 形式）：
$$u_{pid}=k_p e+k_i\!\int e+k_d\,\Delta e,\quad e\notin[-1,1]\Rightarrow I\leftarrow0$$
$$\text{control}=\operatorname{clamp}\big(ff+u_{pid},\,\pm0.5\big)$$
参数：标称 $k_p=-1,\ k_i=0,\ k_d=-50$，积分限 $\pm0.5$；**当前 stand 调试配置把 $k_p/k_i/k_d$ 全置 0**
（roll 环关闭，`roll_bias=0`）。负增益是因为 `roll_bias` 对 roll 的静态增益为负方向。

**作用路径**：`roll_bias` 经仿真/驱动桥转成左右曲柄目标差动（左 $+bias$、右 $-bias$）→ 差动腿长 → 机身侧倾。

### 4.6 轮混控 `WheelLegWheelMixer`

**输入**：`control/wheel_torque`（共模）、`control/wheel_torque_diff`（差速）。
**输出**：`control/wheel_torque_l`、`control/wheel_torque_r`。

**算法**（`wheelleg_wheel_mixer.cpp:39`，共模优先分配）：
```
common = clamp(common, ±L)            # L = wheel_torque_limit（sim 4.88 / stand 2.44）
headroom = L - |common|
diff   = clamp(yaw_sign * diff, ±headroom)   # yaw_sign = -1
tau_l = common + diff
tau_r = common - diff
```
若 common 非有限 → 输出 NaN（桥回落到零力矩路径）。

### 4.7 真机状态估计 `WheelLegStateEstimator` → `wheelleg_state`

| 输出 | 来源 |

| `pitch/roll/yaw(+rate)` | IMU 四元数/重力/陀螺，经 `imu_to_base` 旋到机体系；yaw 解缠 |
| `knee_angle,knee_velocity` | 四关节编码器 → `WheelLegLegModel::forward` 内膝角 $\beta$ |
| `shank_angle,shank_velocity` | $\varphi=\pi-\beta-\alpha$（差分得角速） |

### 4.8 站立层 `WheelLegStandStateMachine` → `wheelleg_stand`

顶层状态机（不自扶正）：双 DOWN = 全禁用；双 MIDDLE（dwell）= arm。arm 后监视共享
`command→trajectory→balance` 链收敛到标称站姿：

| 输出 | 含义 |
|---|---|
| `/wheelleg/stand/armed` | bool |
| `/wheelleg/stand/phase` | 0 disabled / 1 converging / 2 stable |
| `/wheelleg/stand/ready` | 稳定 `stable_seconds` 后为真（MOVE 的前置条件） |

**收敛判据**：$|L_0-0.334|\le0.02$、$|pitch|\le6^\circ$、$|wheel\_velocity|\le0.5$。

### 4.9 运动层 `WheelLegMoveStateMachine` → `wheelleg_move`

分层在 STAND 之后：

- `mode="stand"`：仅 arm STAND，机器人保持标称站姿（move 命令保持 0）。
- `mode="move"`：先 arm STAND；`stand/ready` 后把 DR16 摇杆转发到 `/wheelleg/move/{velocity,yaw_rate}`。

双 DOWN 全禁用（STAND 清 `armed` → move 归零）。参数：`vx_max=0.5`、`yaw_rate_max=1.0`、`deadzone=0.08`。

### 4.10 驱动桥 `WheelLegDriveBridge` → `wheelleg_drive_bridge`

真机与仿真共用：把降阶参考/力矩映到硬件/仿真关节与轮，并在 PC 侧实现关节 PD
（DM 电机 `joint_control_mode: torque`，零 Kp MIT）。

```
输入: /wheelleg/reference/{hip,knee,shank}_angle(_l/_r)   # 逐腿优先，缺失回落到平均
      /wheelleg/control/{wheel_torque_l,wheel_torque_r,roll_bias,com_trim_alpha,
                          hip_torque_ff_{l,r},crank_torque_ff_{l,r}}
      /wheelleg/calib/{active,request_enable,<joint>/torque,<wheel>/torque}
      /wheelleg/state/pitch, /remote/switch/{left,right}
输出: /wheel_leg/<joint>/control_torque、/wheel_leg/{left,right}_wheel/control_torque、
      /wheel_leg/enable_request、/wheelleg/drive/balance_enabled
```

映射（共享模型 + `hardware_*` 标定 `LegCalibration`）：
$$
\beta = knee\_rel\_sign\cdot knee\_ref\ (\pm roll\_bias \text{ 差动}),\qquad
(q_{hip},q_{crank})=F^{-1}(\alpha+\alpha_{trim},\beta)
$$
$$
\tau = k_p(q^*-q)-k_d\dot q+ff,\qquad \tau\in\pm\min(40,\ \text{joint\_max\_torque})
$$

- **多圈对齐**：DM 编码器多圈、目标单圈；每个关节各自取最近圈，并在 $\pm\pi$ 附近加
  `1.05π` 迟滞防抖。髋/曲柄**独立**对齐（曲柄是有限行程的绝对关节，强制共用髋的圈数会把它推出行程）。
- `leg_kp=160, leg_kd=2.5`；`wheel_torque_sign` 按安装镜像（stand `[1,-1]`）。
- **两阶段使能**（真机 `allow_left_middle_right_up=true`）：双 MIDDLE = 仅腿（轮力矩强制 0）；
  左 MIDDLE + 右 UP = 腿 + 轮平衡。arm 仍需 DOWN dwell + DR16 fresh + feedback fresh。
- **轮力矩**：双中/未平衡时 `balance_armed=false` → 0；否则透传 mixer 的左右轮力矩。
- **calib 直通**：`/wheelleg/calib/active` 时用 calib 关节/轮力矩，bridge 仍是唯一硬件力矩写者。
- **倾角保护**：`|pitch| > max_tilt_deg`（stand/sim 均为 60°）→ 全部力矩 0、`enable_request=false`。

> 配置里 `pd_frequency` 目前不使用；`feedback_timeout_s` 由硬件层使用。

## 5. 执行层：仿真桥 `WheelLegSimulation`（实机对应硬件层）

### 5.1 状态映射（输出 `/wheelleg/state/*`）

`publish_state_` **全部由 MuJoCo 真值**换算（`xpos/xanchor/mj_objectVelocity/objectVelocity`），
且通过**共享模型 + canonical 标定**做约定交叉核对，使同一物理位姿在仿真与真机报出相同的
$(\alpha,\beta,\varphi,L_0)$：

| 输出 | 来源/定义 |
|---|---|
| `wheel_velocity` | 左右轮关节角速度均值 × 符号 |
| `shank_angle,knee_angle` | 关节锚点几何 → 共享模型 → 内膝角 $\beta$/shank $\varphi$ |
| `pitch,pitch_velocity` | 机体四元数；速率差分 |
| `leg_length,leg_angle`（+L/R） | 髋/轮锚点几何 → 共享模型 |
| `com_offset` | 整机 CoM 相对轮轴前向投影 $d$ |
| `base_height` | 基座原点高度 |
| `roll,yaw(+rate)` | 四元数/角速度 |
| `velocity,distance` | 机身前向 CoM 速度及积分 |
| `contact_normal_{l,r}`,`slip_{l,r}`,`friction_utilization_{l,r}`,`friction_torque_limit_{l,r}`,`wheel_torque_{l,r}` | **摩擦观测** |

### 5.2 控制映射（输入 `reference/*`、`control/*` → 关节力矩）

`apply_control_`（`:1101`）：

1. **控制力矩**（本配置生效）：驱动桥输出的硬件帧关节力矩经 `map_leg`（Jacobian 转置）映到 MJCF 关节；
   仿真不再额外做腿 PD（`hip_kp/kd` 只在 hold/初始化锁腿时使用）。
2. **力矩模式**：`per_leg_wheel_valid` > `torque_valid` > 速度伺服三级。
3. **roll_bias**：左曲柄 $+bias$、右 $-bias$。
4. **hold 窗口**：`hold_seconds` 内控制器被忽略（底座钉住、腿锁），用于起始位形稳定。
5. **`initial_pose`**：`standing`（默认）/`motor_zero`/`legs_up`/`crouched`；
   `crouched` 会做闭链 settle；`init_pitch_deg/init_hip_delta_deg/init_crank_delta_deg/init_lift_extra` 注入起始位姿扰动。
   `hold_seconds=0` 时从 `standing` 直接进平衡；当前单一 sim 配置不再区分 getup 变体。

### 5.3 轮摩擦上限（**当前实现**）

每步用**上一步接触求解的真实法向力**计算动态摩擦上限：
$$\tau_{w,\lim}=\begin{cases}\text{motor limit (4.88)} & N\le\varepsilon\ (\text{离地，无摩擦})\\
\min\!\big(4.88,\ \mu N(t)\,r\big)& N>\varepsilon\end{cases}$$
另加**电机转速上限** `wheel_speed_limit=49.1 rad/s`：加速力矩随转速线性衰减到 0，制动不受限。

> 旧实现用常数 $\mu Mg r$（静重、整机分配）——非法物理；现改为**逐轮、逐时刻**的 $\mu N(t)r$。
> 由于 `wheel_torque_limit=4.88` < 静重摩擦上限，直行/站立由**电机上限**主导，弧线/抬轮时由**摩擦**主导。

## 6. 闭环回路分析

| 回路 | 开环对象 | 反馈量 | 限幅 |
|---|---|---|---|
| pitch 平衡 | 4 状态 LQR | pitch, pitch_rate, v, x | $\pm4.88$ |
| yaw | 2 状态 LQR | yaw, yaw_rate | $\pm8$ |
| roll | 静态增益 × `roll_bias` | $k_p{=}-1,k_d{=}-50$（stand 调试置 0） | $\pm0.5$ |
| 腿型 | 关节+六杆+PD | 髋 160/2.5，曲柄 160/2.5 | 髋40/曲柄40 |
| 速度/位置 | 姿态 $d$→腿角/腿长（非轮） | $k_v{=}k_x{=}0.5$；步态 $k_{\theta ff},k_v,k_{Lff},k_{dp}$ 当前 stand/sim 置 0 | 腿长 0.22–0.45 |

**外环为什么不用轮**：平衡环独占共模轮力矩；前向运动改由**姿态（CoM 偏置）**驱动，二者不争执行器。

**耦合**：腿动 → pitch（由平衡环吸收）；轮矩反作用 → 腿（由腿 PD + 气簧前馈承担）；
侧倾 → 腿长差（`roll_bias` 只改曲柄目标，间接差动腿长）。

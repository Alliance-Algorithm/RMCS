# 轮腿 V5.0 —— 真机辨识清单与辨识方法

> 目的：轮腿控制器目前在 MuJoCo 里跑通（站立 + 运动）。上真机前，需要把仿真里"来自
> MJCF / 估算 / 整定"的参数替换成实机实测值，否则控制器只是在拟合一个模型。
>
> 本文给出：**需要辨识的量、每个量的物理含义、当前仿真值、辨识方法与工具、以及辨识结果填到哪里**。
> 记号：**[CAD]** 可直接从模型/称重得到；**[ID]** 需要动态系统辨识；**[CAL]** 是标定/对零，不是辨识；
> **[TUNE]** 是控制器整定量（不是辨识对象，但上真机要重调）。
>
> 代码位置：仿真桥 `rmcs_core/src/hardware/wheelleg_simulation.cpp`；参数 `rmcs_bringup/config/wheelleg_sim.yaml`；
> 腿参考外环 `.../controller/wheelleg/wheelleg_trajectory_controller.cpp`；命令规划 `.../wheelleg_motion_planner.cpp`；
> 连杆表 `.../controller/wheelleg/leg_transmission.hpp`。

## 0. 优先级速览

| 优先级 | 类别 | 为什么关键 |
|---|---|---|
| P0 | 电机参数 (kt/齿比/限幅)、关节零位与符号、气簧力曲线 | 直接决定力矩正确性与腿的受力 |
| P0 | 关节摩擦（库仑+黏性） | 决定腿是否抖/补偿是否需要 |
| P1 | 惯量与质心、轮半径、接触摩擦 mu | 决定平衡与运动可行域 |

| P1 | posture map (∂d/∂L0, ∂d/∂pitch)、com_height | 外环靠它把"加速度"翻译成姿态 |
| P2 | 接触刚度/阻尼、滚动阻力、反电动势 | 影响高频与效率，二阶效应 |

## 2. 辨识方法与步骤（公式）

### 2.1 电机力矩常数 kt / 齿比驱动链
台架固定关节，给恒定电流 I（多档），用力矩传感器或已知力臂 L 的重物 m 平衡：
`τ_joint = m·g·L = kt·I·N`（N 为总齿比）→ 线性拟合得 `kt·N` 与零偏。取多档避开摩擦死区。

### 2.2 关节黏性阻尼 + 库仑摩擦（恒速法）
关节抬起（无重力矩或已知重力矩），用速度环维持多个恒速 ωᵢ，记录稳态电流 Iᵢ 与力矩 τᵢ：
`τ = τ_gravity + τ_coulomb·sign(ω) + b·ω`
- 同速正反两次的差 → `2·τ_coulomb`；
- 平均值随 ω 的斜率 → `b`（黏性，含反电动势）。
若含反电动势：`I = (τ_gravity + τ_c + b_m·ω)/kt + ke·ω/R`，可用"断电滑行 vs 通电恒速"分离电气项。

### 2.3 惯量 + 阻尼（断电自由衰减 / 扫频）
- **自由衰减**：给初速后断力矩，记录 ω(t) 衰减包络。`J·ω̇ = -(b·ω + τ_c·sign(ω))`，
  高段拟合 `ln ω` 斜率得 `b/J`，由已知 b 得 J；或直接由衰减周期/对数衰减率。
- **扫频**（`swept_frequency_controller`）：给 `τ = A·sin(ωt)`，记录角度响应，
  在频域算 `θ/τ` 的增益与相位 → 二阶模型 `J·θ̈ + b·θ̇ + k·θ = τ` 拟合出 J、b（k 若为自由关节则 0）。

### 2.4 单摆 / 悬吊法（质心与惯量）
把连杆绕某关节悬挂，令其小角度自由摆动，测周期 T：
`T = 2π·sqrt(I_pivot/(m·g·d))`，配合已知质量与几何可解出 `d`（质心位置）和 `I`。

### 2.5 静力平衡扫掠（重力矩 + posture map）
把腿锁在多个位形，用关节力矩平衡（读保持电流）× 已知几何，得到 `m·g·d(位形)`；
对 `d`、`pitch`、`L0` 做多元回归 → `∂d/∂L0`、`∂d/∂pitch`（即 `accel_*_ff`）。

### 2.6 气簧力-位移
压力机/测力计 + 位移传感器，从中位逐点压缩到全压再返回，记录 `F(u)`；
多项式最小二乘拟合 `c0/c2/c3`（可加一次项）；升/降行程差 → 滞回摩擦。

### 2.7 地面摩擦与滚动阻力
- 平稳驱动，逐步加轮力矩，直到打滑：`μ = F_tangential/(m·g/2)`（实测并取保守值）。
- 自由滑行测减速度 a → 滚动阻力 `F_r = m·a - 气阻`。

### 2.8 plant gain b0（ADRC 核心）
- **阶跃法**：开环（或低增益闭环）给轮力矩阶跃 A，测 θ 的初始角加速度 α：
  `b0 ≈ α/A`（取时间足够短、姿态变化小处）。
- **扫频法**：在关注频段测 `θ(s)/τ(s)`，低频增益 → b0。
- 在若干倾角/腿长下重复 → 得到 `b0(θ, L0)` 的调度表（仿真已知 `b0` 随倾角强非线性）。

## 3. 现有工具与用法

仓库已带辨识组件（`rmcs_core/src/identification/`，已在 `plugins.xml` 注册）：

### 3.1 `StaticTorqueTestController`
用于：测**角度范围**、**中心保持**、**恒力矩/位置测试**（→ 重力矩、摩擦死区、零位）。
- 必要参数：`target`（关节名的接口前缀）、`interval_angle`、`wait_time`、`border_clip`、
  `position_kp/ki/kd`、`velocity_kp/ki/kd` 及各自 `*_min/max`。
- 遥控三档（SW1/SW2）：`kMeasureRange`（记录范围）/`kCenterHold`（保持到范围中心）/`kTestCommand`（测试指令）。
- 典型：在 `kMeasureRange` 内手动摆动关节，再 `kCenterHold` 看**中心保持误差**（用于对零/找中位）。

### 3.2 `SweptFrequencyController`
用于：**扫频辨识**（J、b、b0）。
- 参数：`target`、`sweep`(bool)、`logarithmic`(bool)、`start_freq`、`end_freq`、`duration`、`amplitude`、
  `dc_offset`、`setpoint`、`pid` 及 `position_*/velocity_*` 增益。
- 输出：CSV（`update_count, elapsed_s, pid_output, sweep_output, control_torque, ...`），后处理做频响。

### 3.3 `ValueCollector` + `config/wheelleg_probe.yaml`
把任意 `/wheelleg/...` 话题按周期写 CSV，用于落地测试的原始记录（力、电流、角度、IMU、状态）。

### 3.4 备注
- 电机级标定应尽量在**驱动/电调层**完成（电流环、kt、反电动势），再把结果作为关节模型参数导入仿真。
- 遥控模式切换依赖 `/remote/switch/{left,right}` 与 `/rmcs_msgs/Switch`，辨识时注意安全（限位、急停、支起）。

## 5. 推荐辨识顺序

1. **台架（电机单独）**：kt、齿比、力矩上限、反电动势、转子惯量、电流/电压限。
2. **悬空整机（无接触）**：
   - 编码器零位/符号标定（D）；
   - 关节摩擦（C）：断电自由衰减 + 恒速法；
   - 连杆表核对（A，`leg_transmission`）；
   - 气簧力-位移（E，可整机装好测）。
3. **落地静止**：质心/重力矩、气簧安装几何、接触刚度、μ 与滚动阻力。
4. **落地运行**：
   - `b0(θ,L0)`（阶跃/扫频）；
   - posture map（2.5）；
   - 外环与 ADRC 整定（G/[TUNE]）；
   - **sim2real 对拍**：同一激励（脉冲/扫频/阶跃速度）在仿真与真机对比，残差定位到具体参数。
5. **状态估计**：IMU Allan 方差、里程计标定、打滑率。

## 6. 验收与注意

- **每个参数的验收**：用**独立实验**复核，不要只用拟合残差。例：b0 用另一组阶跃验证；μ 用不同载荷验证；摩擦用不同速度验证。
- **仿真欠建模（上真机必现）**：
  1. 无电机动力学（电流环、力矩-转速曲线、背隙、电压跌落）——真机需在驱动层补；
  2. 状态多为模型真值（`com_*`、`velocity`、`distance`、`d`）——真机需估计；
  3. 接触/地面理想化（平地、μ=2）——真机 μ 更低、有地形与轮胎形变；
  4. 气簧只建了**力**、没建**摩擦/阻尼**——真机摩擦显著；
  5. 闭链是 `connect` **软约束**（数值），真机是**硬铰**——腿的高频特性不同，不要把仿真的 `joint_damping=0.3` 当真实值；
  6. 腿 PD 在仿真内部，真机由**电机驱动层**实现——需要给驱动层设计位置/速度环并整定。
- **安全**：辨识时务必支起机器人/限位/急停；气簧预载很大（~280 N），拆装注意。
- **文档化**：每个实测值连同**测试条件/日期/原始 CSV** 一起记录，便于回溯与 sim2real 对比。

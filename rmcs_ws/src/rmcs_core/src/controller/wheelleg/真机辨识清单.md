# 轮腿真机参数标定 —— 宝宝教程

> 目标读者：**没做过系统辨识也能照着做**。每条参数都写清：**要不要标 → 用哪个工具/文档 → 敲什么命令 → 看什么 → 填到哪里**。
>
> 决策前提（本教程默认）：
> - **气簧先用我们自己的**（BKB0.45-080-205，`gas_spring_full_extension=0.232 / stroke=0.08`），不切真机的 063-172；
> - 真机是用他们那套硬件（`hardware/wheel-leg.cpp`，已在 `plugins.xml` 注册）；
> - 控制器真机链路：`WheelLeg` + `RlController`（RL）或 `WheelLegChassisController`，辨识时用 `WheelLegPairIdentificationController` / `WheelLegWheelIdentificationController`。
>
> 相关文件：
> - 组件源码：`rmcs_core/src/identification/`
> - 一键脚本：`.script/identification/`
> - 配置：`rmcs_bringup/config/wheel-leg-infantry-*-identification.yaml`
> - 本文档姊妹篇（原理）：`执行路线1_数学解析.md`、`执行路线2_控制律设计.md`

## 0. 一张总表：标什么 / 用什么 / 填哪儿

| # | 要标定的量 | 用什么工具 | 结果填到 |
|---|---|---|---|
| 1 | 编码器零位/方向、关节符号 | 手动 + `WheelLegPairIdentificationController`（`model_sign/offset`） | `wheel-leg-infantry-*.yaml` 的 `model_sign/model_offset`；sim `wheelleg_sim.yaml` 的 `hip_zero/knee_zero_l/knee_zero_r/hip_sign/state_*_sign` |
| 2 | 关节重力矩 / 库仑摩擦 | `StaticTorqueTestController` + `fit_gravity_torque.py` | 前馈/`frictionloss`（MJCF 或驱动器补偿） |
| 3 | 关节黏性阻尼 + 惯量 | `SweptFrequencyController` + `fit_sweep_graybox.py` | MJCF `dof_damping`/`armature` |
| 4 | 整腿 plant（重力+弹簧+摩擦，耦合） | `WheelLegPairIdentificationController` → bag → `fit_wheel_leg_pair_bag.py` | 控制前馈 / 仿真 `pair` 模型 |
| 5 | 轮子力矩常数/摩擦/轮速环 | `WheelLegWheelIdentificationController` + `fit_wheel_speed_bag.py` / `fit_friction_velocity_pid.py` | `wheel_*` 参数 |
| 6 | 气簧 F-u 曲线/行程 | 压力机（外部工装，非软件） | `gas_spring_*` |
| 7 | 轮-地摩擦 μ、滚动阻力 | 牵引/滑行试验 | `friction_coefficient`、接触参数 |
| 8 | pitch/yaw plant gain `b0` | 阶跃/扫频（`SweptFrequencyController` 思路或 RL 侧） | `wheelleg_balance_controller.b0`、`wheelleg_yaw_controller.b0` |
| 9 | IMU 零偏/噪声/安装 | Allan 方差 + 静态对齐 | `imu_to_base`、滤波参数 |

> 标定量**最终都要和"真机实际配置"一致**。每次标完把结果写进对应 yaml，并在提交里注明"实测/日期/条件"。

## 1. 准备工作（每次都做）

> 以下命令默认在仓库根 `/workspaces/RMCS` 执行。

```bash
# 1) 本地编译（改了 C++ 才需要）
.script/build-rmcs

# 2) 同步到真机：把本地 install 推到真机 /rmcs_install
.script/sync-remote          # 需要已配置好 ssh 别名 `remote`

# 3) 确认远端机器人类型（辨识脚本会在远端自动 set-robot）
#    手动看：远端 /usr/local/bin/set-robot wheel-leg-infantry-v6-L01-identification
```

**安全红线（务必）**
- 腿辨识：**机器人必须支起，轮子离地**（脚本里的 `wheels_off_ground: true`、`support_fixture: rigid_fixed_frame`）。
- 遥控器两开关定义（后面会用）：
  - **两开关都拨 DOWN** → 复位/禁用（发 NaN 力矩、清错）。
  - **两开关都拨 MIDDLE** → 开始/使能辨识序列。
  - 中间任何 UP/掉线 → 取消。
- 任何异常先拨 **双 DOWN**。

启动前自检（脚本已内置，也可手动）：
```bash
python3 .script/identification/check_wheel_leg_profile.py \
  rmcs_ws/src/rmcs_bringup/config/wheel-leg-infantry-v6-L01-identification.yaml
```

## 2. 一键流程（推荐）：整腿 / 轮子辨识

脚本：`.script/identification/remote-wheel-leg-identify`

用法总览：
```
remote-wheel-leg-identify start-v6 L01      # 起一个真机 executor 并录制"整腿"序列
remote-wheel-leg-identify record-v6 L01     # 只录制一个已在跑的 executor
remote-wheel-leg-identify start-pd-loaded   # 旧版单侧 pair（PD-loaded）
remote-wheel-leg-identify record-pd-loaded  # 只录制一个已在跑的旧版单侧 pair
remote-wheel-leg-identify start-wheels      # 轮子辨识
remote-wheel-leg-identify stop              # 停止录制并封包
remote-wheel-leg-identify status            # 看 screen / 话题
```
（Run 代号可换：`L01 L02 L03 LJ01 LJ02 R01 R02 R03 RJ01 RJ02`。）

### 步骤 A：整腿 plant 辨识（重力+弹簧+摩擦耦合）

1. 支起机器人；上电；遥控器两开关拨 **DOWN**（进安全态）。
2. 起流程并录制：
   ```bash
   .script/identification/remote-wheel-leg-identify start-v6 L01
   ```
   脚本会自动：校验 profile → 起真机 executor（`rmcs.launch.py robot=wheel-leg-infantry-v6-L01-identification`）→ 起 rosbag → 等到"录到话题/recorder 就绪"才提示可以开始。
3. 看到提示后，遥控器两开关拨到 **MIDDLE** → 开始激励（dwell / 慢扫 / two-tone / chirp 等，50 Hz 参考、1 kHz 控制）。跑完一轮再拨 **DOWN**。
4. 停止并封包：
   ```bash
   .script/identification/remote-wheel-leg-identify stop
   ```
   产物在远端 `/root/identification_bags/v6-L01-<时间>/`：`bag/`、`profile.yaml`、`calibration.json`、`controller-source.tar.gz` 等。
5. 拉回本地（用你的同步工具，或 scp 该目录），然后导出+拟合：
   ```bash
   run=/path/to/v6-L01-xxxx
   python3 .script/identification/export_identification_bag.py \
     --bag "$run/bag" --output "$run/data.npz" \
     --calibration "$run/calibration.json" --profile "$run/profile.yaml"
   python3 .script/identification/fit_wheel_leg_pair_bag.py \
     --npz "$run/data.npz" --profile "$run/profile.yaml" --output "$run/report.json"
   ```
   `report.json` 里就是这条腿的耦合 plant（重力/弹簧/摩擦一起拟合，`fit_wheel_leg_pair_bag.py` 头部说明了"pose load 不可分离"）。
6. **填哪**：把 report 里的等效参数填进控制器前馈 / 仿真 pair 模型；`fit_*` 会同时写 `.replay.npz` 供定基复现。

### 步骤 B：轮子辨识（电流→力矩、摩擦、轮速环）

1. 支起（轮子离地），**四个 DM 腿电机保持 disabled**（脚本会校验）。
2. 起流程（会先要求"双 DOWN 停留"再"双 MIDDLE"）：
   ```bash
   .script/identification/remote-wheel-leg-identify start-wheels
   ```
   遥控器：**先两开关 DOWN 停留 ~0.5 s，再拨 MIDDLE** → 跑多频带轮速序列（`wheel_low_speeds/wheel_speeds/coast/step/chirp`）。
3. 停止：`... remote-wheel-leg-identify stop`。
4. 拟合：
   ```bash
   python3 .script/identification/extract_wheel_speed_bag.py <run> <out.npz>
   python3 .script/identification/fit_wheel_speed_bag.py <run> <arrays.npz> <report.json>
   # 或轮速环增益：
   python3 .script/identification/fit_friction_velocity_pid.py <sweep.csv> \
     --input-signal torque --fc-hz 20
   ```
5. **填哪**：`wheel_reduction_ratio`、`wheel_velocity_kp/ki`、轮力矩/电流上限（`wheel_torque_cap`、`wheel_current_limit_a`；sim 侧 `wheel_motor_torque_limit`）。

## 3. 单关节流程（本地/工装）：重力矩与摩擦

用通用组件 `StaticTorqueTestController`（静态）和 `SweptFrequencyController`（扫频）。它们由 yaml 的 `components` 列表加载。

最小配置示例（新建 `config/wheelleg-ident-single.yaml`，`wheel_leg` 段为 `WheelLeg`
硬件必填参数，照抄真机 profile）：
```yaml
rmcs_executor:
  ros__parameters:
    update_rate: 1000.0
    components:
      - rmcs_core::hardware::WheelLeg -> wheel_leg
      - rmcs_core::controller::identification::StaticTorqueTestController -> static_torque
wheel_leg:
  ros__parameters:
    board_serial: ""              # CAN 板序列号
    require_enable_request: true
    joint_control_mode: "torque"
    allow_set_zero: false
    dm_master_ids: [1, 2, 1, 2]
    dm_mit_position_max: [12.5, 12.5, 12.5, 12.5]
    dm_mit_velocity_max: [45.0, 45.0, 45.0, 45.0]
    dm_mit_torque_max: [54.0, 54.0, 54.0, 54.0]
    dm_control_torque_max: [2.0, 2.0, 2.0, 2.0]
static_torque:
  ros__parameters:
    target: /wheel_leg/left_hip_joint
    interval_angle: 0.1      # 每个采样角度间隔
    wait_time: 1.0           # 每点等待
    border_clip: 0.05
    position_kp: 0.5
    position_ki: 0.0
    position_kd: 0.02
    velocity_kp: 0.6
    velocity_ki: 0.0
    velocity_kd: 0.0
```
运行：
```bash
ros2 run rmcs_executor rmcs_executor --ros-args --params-file <该 yaml>
# 遥控器（static_torque 用）：两开关都 MIDDLE=测量范围, 左 MIDDLE + 右 UP=开始测试
```
拟合（生成的 CSV 里含 torque/velocity/angle 列）：
```bash
python3 .script/identification/fit_gravity_torque.py <static.csv> \
  --target /wheel_leg/left_hip_joint --signal torque --json-output gravity.json
```
扫频版：
```bash
# swept_frequency 组件参数：target, sweep:true, start_freq, end_freq, duration, amplitude, dc_offset, pid...
python3 .script/identification/fit_sweep_graybox.py <sweep.csv> \
  --target /wheel_leg/left_hip_joint --input-signal torque --json-output sweep.json
```
**填哪**：重力矩→前馈/`frictionloss`；`sweep.json` 里的惯量 J/黏性 b→MJCF `armature`/`dof_damping`。

## 4. 工装类：气簧（保持用我们自己的）

**没有软件可自动标**，需要用压力机/测力计：
1. 拆下气簧，台架固定，从中位逐点压缩到全压再返回，记录 **力 F ↔ 压缩 u**。
2. 多项式拟合 `N(u)=c0+c2·u²+c3·u³`（升/降行程各拟合一次，取差为滞回摩擦）。
3. **填哪**（`wheelleg_sim.yaml` 的 `wheelleg_sim` 段）：
   ```yaml
   gas_spring_enabled: true
   gas_spring_full_extension: 0.232   # 全伸销距（实测）
   gas_spring_stroke: 0.08            # 行程（实测）
   gas_spring_c0: 280.0
   gas_spring_c2: 122.7359
   gas_spring_c3: 53.9698
   gas_spring_sign: 1.0               # 装好后跑一次确认"推伸展"，反了改 -1
   ```
4. 验收：跑一次仿真，看日志 `gas spring L: pin_len=... F=...`；再上真机看腿是否被顶起。

> 注意：我们模型的锚点几何和真机一致（CAD 零位销距 0.1623 = 他们的 nominal），所以气簧力模型可迁移；但**弹簧号/全伸/行程以我们实装为准**，不要照抄他们的 063-172。

## 5. 落地类：轮-地摩擦、滚动阻力、b0、IMU

### 5.1 轮-地摩擦 μ
1. 落地平地，逐步加轮力矩直到打滑，记打滑临界切向力 F 与法向 N：`μ = F/N`。
2. **填哪**：`friction_coefficient`（sim）、侧向限幅 `friction_mu`（planner）。

### 5.2 滚动阻力
自由滑行，测减速度 a → 阻力矩 = 估算。填驱动器摩擦补偿。

### 5.3 plant gain `b0`（pitch / yaw）
1. 给轮（或差速轮）一个**力矩阶跃**（或用 `SweptFrequencyController` 思路扫频），测角加速度 α。
2. `b0 ≈ α / τ`（取时间足够短处）；在几个倾角/腿长下重复得 `b0(θ,L0)`。
3. **填哪**：`wheelleg_balance_controller.b0`、`wheelleg_yaw_controller.b0`。

### 5.4 IMU / 状态估计
1. 静止采样 ≥30 min，Allan 方差得 bias、随机游走。
2. 静态对齐测 `imu_to_base`（本车为 Identity：BMI088 +X前/+Z上/+Y左）。
3. 轮里程计标定有效轮半径与打滑率。
4. **填哪**：估计器参数（真机状态估计模块）。

## 7. 验收 & 注意

- 每个标定量要用**另一组独立实验**复核（别只看拟合残差）：b0 换一组阶跃、μ 换载荷、摩擦换速度。
- 仿真和真机**不是同一个模型/版本**时，标定值**不要跨模型照搬**。注意量纲/定义别混：例如轮距 `0.4373`（轮毂/触地点，tip-over 用）与 `0.3966`（轮电机间距）是两个量；膝内角机械限位用 **40..105°**（与 V6 模型域一致）。
- `connect`（MuJoCo 闭链）是**软约束**，`joint_damping=0.3` 是压极限环的工程值，**不是真机摩擦**。真机要用本教程实测。
- 气簧预载大（~280 N），拆装注意安全。
- 所有辨识记录（bag/CSV/report.json）连同 profile 一起归档，便于复现和 sim2real 对比。
